# LexiQuest · Calm Learning UI

> ระบบออกแบบหลักสำหรับทุกหน้าของ LexiQuest ต้องรองรับภาษาไทย ตัวอักษรขนาดใหญ่ โหมดลดการเคลื่อนไหว และการใช้งานมือเดียวบน Android

**ปรับปรุง:** 2026-10-20
**แนวทาง:** Calm Learning UI · Android-first · Material 3 · Thai-first
**เป้าหมาย:** ช่วยให้ผู้เรียนเห็นสิ่งที่ควรทำ เหตุผลของคำแนะนำ และขั้นตอนถัดไปโดยไม่ถูกกรอบ สี หรือรางวัลรบกวน

**หลักฐานเลย์เอาต์:** REA runtime ของ Duolingo/AllTCAS, REA public flow ของ Astra AI และ Android adaptive guidance สรุปไว้ใน `docs/research/2026-10-18-duolingo-astra-alltcas-layout-synthesis.md`

## หลักการ

1. หนึ่งหน้ามีเป้าหมายหลักหนึ่งอย่าง และมีปุ่มหลักเพียงหนึ่งปุ่มเมื่อทำได้
2. ใช้ลำดับ `แผนวันนี้ → ฝึก → บันทึกหลักฐาน → ให้คำแนะนำ → ทำขั้นถัดไป`
3. แยกสถานะการเรียน แรงจูงใจ และงานวิจัยออกจากกันด้วยข้อความและสีเชิงความหมาย
4. ลดจำนวนกรอบซ้อน เงาหนัก แคปซูล และข้อความตัวพิมพ์ใหญ่
5. ทุกข้อมูลสำคัญต้องอ่านได้โดยไม่พึ่งสี ไอคอน หรือการเคลื่อนไหวเพียงอย่างเดียว

- หน้า onboarding ถามทีละเรื่องพร้อม progress และ Back ที่มองเห็นได้
- หน้า AI เริ่มจากแหล่งบริบท/คำถาม แล้วค่อยแสดงขั้นอธิบาย การตรวจ และทางไปต่อ

## ตัวอักษร

- ใช้ `Noto Sans Thai` สำหรับภาษาไทย อังกฤษ และตัวเลขในผลิตภัณฑ์
- น้ำหนักที่อนุญาต: 400, 500, 700, 800
- หัวเรื่องใหญ่: 32–44sp, line-height 1.2, น้ำหนัก 800
- ชื่อหน้า: 20–24sp, line-height 1.35, น้ำหนัก 700
- เนื้อหาหลัก: 16sp, line-height 1.55, น้ำหนัก 400
- ป้ายและปุ่ม: 14–16sp, line-height 1.4, น้ำหนัก 700
- คำอธิบาย: 13–14sp, line-height 1.5, น้ำหนัก 400/500
- ห้ามใช้ negative letter-spacing กับภาษาไทย และห้ามบีบ line-height ต่ำกว่า 1.35
- รองรับ system text scaling โดยไม่ตัดข้อความหรือใช้กรอบสูงตายตัว

## ระยะและโครงหน้า

ใช้กริด 4dp และให้ 8dp เป็นจังหวะหลัก

| Token | ค่า | การใช้ |
| --- | --- | --- |
| `space-1` | 4dp | ระยะภายในที่ชิดกัน |
| `space-2` | 8dp | ช่องไฟไอคอนและข้อความ |
| `space-3` | 12dp | ช่องไฟองค์ประกอบย่อย |
| `space-4` | 16dp | padding การ์ดและขอบจอขั้นต่ำ |
| `space-5` | 24dp | แบ่งกลุ่มเนื้อหา |
| `space-6` | 32dp | แบ่งส่วนใหญ่ |

- ขอบจอมือถือ: 16dp ที่ความกว้าง 320dp; 20dp ตั้งแต่ 360–599dp และเคารพ safe area
- ความกว้างเนื้อหาสูงสุดบนจอใหญ่: 1,200dp
- เปลี่ยน NavigationBar เป็น NavigationRail เมื่อพื้นที่พอ
- ใช้ `LayoutBuilder`, `Flexible`, `Expanded` และความสูงตามเนื้อหา
- ระยะระหว่างหัวข้อกับเนื้อหาต้องมากกว่าระยะระหว่างรายการในกลุ่มเดียวกัน

## องค์ประกอบ

### ปุ่ม

- พื้นที่กด Android ขั้นต่ำ 48×48dp
- ความสูงแนะนำ 48–52dp, radius 14dp
- Primary ใช้สี primary และข้อความขาว
- Secondary ใช้พื้น primary-soft หรือกรอบ 1dp
- ไม่ใช้ปุ่มทรงแคปซูลยาวกับทุก action
- แสดง pressed, focus, disabled และ loading โดยไม่เปลี่ยน layout

### การ์ด

- พื้นขาว กรอบ 1dp สี border, radius 16dp
- padding 16dp, ช่องระหว่างการ์ด 8–12dp
- ใช้เงา `0 8px 20px rgba(17,21,34,.08)` เฉพาะการ์ดลอยหรือ feedback
- ไม่ซ้อนการ์ดหลายชั้นถ้าเส้นแบ่งหรือช่องไฟสื่อกลุ่มได้

### อินพุต

- สูงอย่างน้อย 48dp, radius 12dp, padding แนวนอน 14–16dp
- label อยู่นอกช่องหรือคงตำแหน่งเมื่อมีค่า
- focus ring ชัดเจน 3dp และมีข้อความ error ใต้ช่อง

### ไอคอนและสถานะ

- ใช้ไอคอนเวกเตอร์ชุดเดียว เช่น Material Symbols Rounded หรือ Lucide
- ขนาดภาพ 20–24dp ภายในพื้นที่กดอย่างน้อย 48dp
- ห้ามใช้ emoji หรืออักขระ Unicode เป็นโครงสร้างปุ่ม
- ความสำเร็จ จุดอ่อน ออฟไลน์ จำกัด และ error ต้องมีข้อความกำกับ

## Motion

- micro interaction 120ms, transition 180ms, page transition สูงสุด 240ms
- ใช้ easing แบบ Material และหลีกเลี่ยง bounce ในหน้าข้อมูล
- ห้ามใช้ scale หรือ translate ที่ทำให้ layout ขยับ
- เมื่อเปิด Reduce Motion ให้ตัด animation ที่ไม่จำเป็นและแสดง final state ทันที

## รูปแบบหน้าหลัก

1. **Home:** คำทักทาย → แผนวันนี้ → เหตุผลของคำแนะนำ → เส้นทาง → โหมดฝึกอื่น
2. **Practice:** ความคืบหน้า → โจทย์เดียว → ตัวเลือก → feedback ที่คงอยู่ → ปุ่มทำต่อ
3. **Progress:** สรุปแนวโน้ม → หลักฐาน → จุดอ่อน → action ที่แนะนำ
4. **Library:** ค้นหา/กรอง → หมวด → รายการคำ → รายละเอียดและ action ฝึก
5. **Settings:** บัญชี → การแสดงผล → สิทธิ์อุปกรณ์ → AI/BYOK → งานวิจัย → ส่งออก/ลบข้อมูล

## Layout archetypes

1. **Focus:** หนึ่งโจทย์ หนึ่งคำตอบ หนึ่งขั้นถัดไป
2. **Browse:** ค้นหา เลือก และเปิดรายละเอียด
3. **Evidence:** ผลที่ตรวจสอบได้ เหตุผล และคำแนะนำ
4. **Setup:** กรอกหรือตัดสินใจทีละกลุ่ม

ชื่อผู้ใช้ทั่วไปต้องใช้ `เลือกวิธีฝึก`, `คำที่ควรฝึกเพิ่ม`, `ผู้ช่วยฝึกภาษาอังกฤษ`, `ช่วยฉันคิดทีละขั้น`, `อธิบายให้เลย`, `ความก้าวหน้าจากการฝึก` และ `แลกด้วยคะแนน` แทนศัพท์ภายในหรือชื่อ provider

## สิ่งที่ห้ามใช้

- ระยะ 13/17/19dp แบบไม่มีระบบ
- การ์ดทุกส่วนและกรอบซ้อนโดยไม่จำเป็น
- pill shape กับปุ่มหลัก การ์ด หรือฟิลด์ทุกชนิด
- เงาหนา ขอบ 3–4px และ claymorphism
- ฟอนต์ Baloo 2 หรือ Comic Neue สำหรับภาษาไทย
- ตัวอักษรเล็กกว่า 12sp และสีเทาคอนทราสต์ต่ำ
- fixed height ที่ตัดข้อความเมื่อขยายฟอนต์
- สีอย่างเดียวเพื่อสื่อถูก/ผิด พร้อม/จำกัด หรือสถานะงานวิจัย
- รางวัลที่ดูเหมือนเปลี่ยน mastery หรือผลการเรียน
