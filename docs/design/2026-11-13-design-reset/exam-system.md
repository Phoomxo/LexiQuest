# LexiQuest ออกโจทย์อย่างไร และหน้าฝึกควรบอกอะไรผู้เรียน

ตรวจสายการเรียกใน `lib/` ของสาขา `feature/associative-reading-loop` วันที่ 13 พฤศจิกายน 2026 แอปมีทั้งโจทย์ที่เริ่มได้จากเมนูจริง หน้าที่ต้องมีคำหรือบทอ่านส่งเข้าไป และแบบที่อยู่ใน TOR แต่ยังต้องพัฒนา การนับไฟล์ Dart ทำให้มองข้ามทั้งสามกรณี

## ตามคำหนึ่งคำตั้งแต่เลือกจนกลับมาฝึก

1. **เลือกคำ** แบบฝึกทั่วไปอ่านคำของผู้เรียนที่ยังใช้งานได้ กรองตามหมวดเมื่อเลือกหมวด เรียงตามรหัส แล้วเอาไม่เกิน 10 คำตามค่าเริ่มต้น ชุดทบทวนใช้รายการที่ถึงกำหนดและเรียงจากกำหนดเก่าสุด ค่าเริ่มต้น 20 คำ การฝึกคำที่เพิ่งพลาดกับการฝึกจากข้อความส่งรหัสคำเฉพาะเข้าไปและใช้คำอื่นในคลังช่วยสร้างตัวเลือกได้ [ตัวเลือกชุดคำในฐานข้อมูล](../../../lib/features/learning/data/drift_learning_repository.dart) · [จุดเริ่มของแต่ละกิจกรรม](../../../lib/features/learning/application/learning_use_cases.dart)
2. **ออกข้อเลือกความหมาย** ตัวสร้างรวมคำแปลไม่ซ้ำ เรียงข้อความ ตัดคำแปลที่ตรงกับคำตอบออก แล้วเลือกตัวลวงไม่เกิน 3 ตัว ตำแหน่งเฉลยหมุนตามผลรวมรหัสอักขระของ word ID ดังนั้นคำที่ได้ซ้ำจากชุดเดิมอาจมีลำดับตัวเลือกเดิม และคลังที่มีเพียงความหมายเดียวสามารถสร้างข้อที่มีเพียงเฉลยได้ ในกรณีนี้ข้อเสนอคือเสนอบัตรทบทวน พร้อมบอกว่าเพิ่มคำอีกหนึ่งความหมายก่อนฝึกเลือกตอบ ส่วนการตรวจว่าตัวลวงมีความหมายใกล้เคียงแต่ผิดแน่ในบริบท ยังต้องสร้างและทดสอบเพิ่ม [ตัวสร้างคำถาม `_questions`](../../../lib/features/learning/application/learning_use_cases.dart)
3. **ระหว่างตอบ** แบบเลือกความหมายในแอปมีคำใบ้ชนิดคำและปุ่มเปิดเฉลย การเปิดเฉลยส่งผลเป็นตอบไม่ถูก การส่งซ้ำหลังเกิดข้อผิดพลาดใช้รหัสคำตอบและเวลาเดิม UI แสดงเฉลยเมื่อบันทึกสำเร็จ สิ่งที่ควรเห็นระหว่างฝึกคือคำที่เลือก เทียบกับเฉลย เหตุผลสั้น ๆ และทางไปต่อ ไม่ควรแสดงคะแนนสำเร็จขณะที่ข้อมูลยังรอบันทึก [ลำดับการตอบและการส่งซ้ำ](../../../lib/screens/quiz_screen.dart)
4. **จบรอบ** แอปสรุปจากจำนวนถูกและผิดที่บันทึก หากพลาดจะส่งรหัสคำที่พลาดกลับเข้าแบบเลือกความหมาย ต้นแบบเสริมให้เปิดดูเฉพาะคำที่พลาดและลองนึกเองก่อนเปิดคำแปล คะแนนรอบแรกคงเดิม [ทางไปฝึกซ้ำหลังดูผล](../../../lib/screens/quiz_screen.dart)
5. **กลับมาฝึกในวันถัดไป** นโยบายหลักใช้ผลถูก/ผิด ระยะแรกเมื่อตอบถูกต่อเนื่องคือ 1, 3, 7, 14 วัน หลังจากนั้นเพิ่มเป็นสองเท่าของช่วงก่อนหน้า ตอบผิดเริ่มใหม่ที่ 1 วัน ป้าย “ถึงเวลาทบทวน” ใช้วันที่กำหนด ส่วน “คำที่ยังสับสน” ให้ฝึกซ้ำได้ในวันนี้ [นโยบายเว้นระยะ](../../../lib/features/learning/domain/srs_policy.dart) · [ทางเข้าและลำดับคำแนะนำ](../../../lib/screens/choose_mode_screen.dart)

## เหตุผลที่เปลี่ยนโจทย์และเฉลย

การทดลองกับคู่คำศัพท์ภาษาต่างประเทศพบว่าการทดสอบให้นึกซ้ำช่วยการจำเมื่อวัดภายหลัง ทีมจึงเสนอให้นึกคำที่เพิ่งพลาดก่อนเปิดคำแปล และแยกผลครั้งแรกออกจากการฝึกซ้ำ หลักฐานดังกล่าวมาจากงานทดลองของผู้วิจัย ผลของ LexiQuest ยังต้องทดสอบกับผู้เรียนเป้าหมาย [Karpicke และ Roediger, 2008](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)

การทดลองแบบเลือกตอบพบว่าการให้เฉลยช่วยลดการตอบตามตัวลวงในการวัดครั้งถัดไป ข้อเสนอของ LexiQuest จึงแสดง *station = สถานี* คู่กับ *platform = ชานชาลา* เมื่อเลือกผิด แล้วชวนไปฝึกคำที่พลาดโดยไม่รวมคะแนนใหม่เข้ากับรอบเดิม [Butler และ Roediger, 2008](https://profiles.wustl.edu/en/publications/feedback-enhances-the-positive-effects-and-reduces-the-negative-e/)

ก่อนใช้ผลเพื่อปรับแผนเรียน ต้องทดสอบชุดข้อมูลคลังว่าง คำเดียว ความหมายซ้ำ คำพ้องที่ถูกได้หลายข้อ และคำตอบที่ส่งซ้ำหลังบันทึกล้มเหลว ให้ตรวจว่าคะแนนแยกเลือกตอบ นึกเอง และดูเฉลยได้อย่างไร โดยเฉพาะกรณีที่มีทางตอบได้เพียงทางเดียว การทดลองต้นแบบยังไม่ครอบคลุมการรับข้อมูลอิสระ ระบบเสียงจริง การเขียนด้วยปากกา การบันทึกข้ามรอบ หรือผลการเรียนระยะยาว
