# ฝึกภาษาและคลังคำศัพท์: ทำให้ชื่อเมนูบอกหน้าที่

เปิด [ต้นแบบสำหรับลองกด](ลองใช้งาน.html) หรือ [ไฟล์ที่แก้เลเยอร์ได้ใน FigCraft](LexiQuest.figcraft) · [เทียบสองหน้าก่อนและหลัง](navigation-before-after.png)

คนที่เพิ่งเปิด LexiQuest ควรเห็นว่าฝึกอะไรได้ทันที ส่วนคนที่เคยเก็บคำไว้ควรเปิดหาคำนั้นได้โดยไม่ต้องเลือกรูปแบบการฝึก ทั้งสองงานเคยแข่งกันเอง: หน้า “วันนี้” มีทั้งวันที่ หัวข้อชวนเลือก และป้าย “คำ / อ่าน / ฝึก”; หน้าคลังมีทั้งคำค้างทบทวน เครื่องมือ และชุดคำที่มีน้ำหนักพอ ๆ กัน

| ตำแหน่ง | เหตุผลที่จัดแบบนี้ | สิ่งที่ลองกดได้ |
|---|---|---|
| ฝึกภาษา | ให้เห็นคำที่ถึงคิวพร้อมประโยคใช้งาน ป้ายชานชาลาเลข 2 ช่วยอ่าน “Meet me on platform two.” ส่วนภาพไม่มีคำแปลให้เห็นก่อนลองนึกเอง | “ทบทวนคำนี้” เปิดบัตรคำ “ฝึกจากชุดคำ” เปิดตัวเลือกชุด “อ่านเรื่องนัดกันที่สถานี” เข้าบทอ่านโดยตรง |
| ฝึกเพิ่มเติม | งานที่เป็นทางเลือกใช้แถวข้อความ ชื่อแถวบอกว่าจะทำอะไร ไม่ต้องถอดความป้ายหนึ่งพยางค์ | “ดูแบบฝึกทั้งหมด” → “ฝึกจากข้อความของฉัน”; งานที่มอบหมายเข้าจาก “งานที่ได้รับ” ที่หัวหน้า |
| คลังคำศัพท์ | แยก **หาของเดิม** (ค้นหาคำหรือเปิดชุด) จาก **เพิ่มของใหม่** (ปุ่มเดียว). ภาพรถไฟและหม้อช่วยแยกชุด แต่ชื่อชุดยังอ่านได้แม้ไม่เห็นภาพ | ค้น station → เปิดคำ → กลับชุด; “เพิ่มคำ” → พิมพ์คำศัพท์ / ถ่ายภาพสิ่งของ / นำเข้าจากไฟล์ |
| เมนูหลัก | “ฝึกภาษา / คลังคำศัพท์ / ความก้าวหน้า / บัญชี” ใช้ชื่อและตำแหน่งเดียวกันทุกแท็บ หน้าหลักทั้งสี่ใช้แนวซ้าย 24 px หัวเรื่องขนาด 32 px บนผืน 390 × 844 ส่วนคำภาษาอังกฤษเป็นเนื้อหาที่ฝึก | สลับออกจากงานแล้วกลับแท็บฝึกภาษา หรือลองเปิดชุดของใช้ในครัวก่อนและหลังเก็บคำจากกล้อง |

**หลักฐานที่ใช้ตัดสินใจ** — [ภาพ AllTCAS บนเครื่องจำลอง](D:/REA/alltcas/reference/ldplayer-runtime/vocab-landscape.png) แบ่งงานทบทวน ชุดที่เลือกล่าสุด และวิชาออกจากกัน [ภาพ All Vocab แนวตั้ง](D:/REA/alltcas/rebuild/checks/ldplayer-1.5.3-arm64/signed-phone-vocab/screen.png) เป็นงานสร้างกลับ ใช้เทียบสัดส่วนเท่านั้น. [Quizlet Learn](https://help.quizlet.com/hc/en-us/articles/360030986971-Studying-with-Learn) เริ่มฝึกโดยเปิดชุดก่อน; [Duolingo Practice](https://blog.duolingo.com/guide-to-duolingo-practice-hub/) ให้เลือกงานเฉพาะ เช่น ทบทวนข้อผิดหรือฝึกฟัง. สำหรับ LexiQuest จึงเก็บชื่อชุดและตัวอย่างคำไว้ในคลัง ส่วนหน้าฝึกใช้คำกริยาที่อธิบายผลของการแตะ ภาพประกอบและสีในต้นแบบเป็นของ LexiQuest

**วิจารณ์หลังเห็นภาพจริงด้วย Impeccable 4.9.0** — เมื่อทบทวนจบ หัวข้อหน้าแรกเปลี่ยนเป็น “ทบทวนครบแล้ว” แต่ทางฝึกในคลังเดิมยังเรียกคำเดียวกันว่า “ถึงเวลาทบทวน” แก้ให้เรียก “ฝึกด้วยบัตรคำ” และบอกว่าฝึกซ้ำได้ อีกจุดคือ “ค้นหาชุดเรียน” พาคนไปเลือกรายการหรือกรอง ไม่เหมือนช่องค้นหาคำบนหน้าเดียวกัน จึงเปลี่ยนชื่อทางเข้าและหัวเรื่องปลายทางเป็น “เลือกชุดคำศัพท์” ตรวจซ้ำว่าทำงานที่ได้รับก่อนหรือทบทวนคำก่อนก็กลับมาเห็นทั้งสองผลได้ [ปุ่มที่กดและปลายทางจริง 8 งาน](menu-present.json)

**สิ่งที่ยังต้องพิสูจน์กับคนใช้** — การรวมเครื่องมือเพิ่มคำลดจำนวนตัวเลือกบนหน้าคลัง แต่เพิ่มหนึ่งครั้งที่ต้องแตะก่อนเปิดกล้อง ให้ผู้เรียนไทยเปิดต้นแบบจากหน้าแรกแล้วบอกเพียงว่า “อยากเก็บคำอังกฤษจากถ้วยใบนี้ แล้วกลับมาหาคำเมื่อกี้” สังเกตว่าจุดแรกที่แตะคืออะไร และกลับมาเจอคำเองได้ไหม อีกงานหนึ่งคือให้ทบทวนคำที่ถึงคิวแล้วกลับไปฝึกอย่างอื่น ดูว่าผู้เรียนเห็นความต่างระหว่างงานค้างกับงานเสร็จหรือไม่ การกดอัตโนมัติพิสูจน์ปลายทางได้ แต่ตอบสองคำถามนี้แทนผู้เรียนไม่ได้
