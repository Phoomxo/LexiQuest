# กล้องเก็บคำศัพท์

เปิดรอบนำเสนอใหม่แล้วลองแตะ **คลังคำศัพท์ → ของใช้ในครัว** จะเห็นชุดว่าง กลับคลังแล้วแตะ **เพิ่มคำ → ถ่ายภาพสิ่งของ** สแกนถ้วย ตรวจคำแปล แล้วแตะ “เก็บคำว่า cup” เมื่อกลับเข้าคลังหลังสลับแท็บ ให้เปิดชุด “ของใช้ในครัว” หรือแตะช่อง “ค้นหาคำในคลัง” แล้วเลือก “ค้นว่า cup” ทั้งสองทางควรพบคำที่มีป้าย “เก็บจากกล้อง” หากปฏิเสธสิทธิ์หรือบันทึกล้มเหลว ให้ตรวจว่าชุดยังว่าง [เปิดหน้าคลัง](ลองใช้งาน.html#categories_page) · [กรณีตรวจสถานะการเก็บคำ](camera-boundaries.json)

**โจทย์สำหรับลองกับผู้เรียนจริง:** “สมมติว่าเห็นถ้วยบนโต๊ะ อยากรู้ว่าเรียกเป็นภาษาอังกฤษว่าอะไรและเก็บไว้ฝึก ลองทำให้ดู แล้วเปิดงานอื่นสักครู่ก่อนกลับมาให้ดูคำเดิม” เริ่มจากหน้า “ฝึกภาษา” โดยไม่ชี้ปุ่ม จดว่าผู้เรียนเลือกทางไหน เปิดคำที่เก็บแล้วได้เองหรือไม่ และต้องช่วยตรงไหน อย่าแสดงลำดับปุ่มด้านบนให้ผู้เรียนก่อนเริ่ม

ผู้เรียนเปิดกล้องเพื่อเปลี่ยนสิ่งของที่เห็นเป็นคำที่จำและนำไปใช้ได้ ตัวอย่างในต้นแบบจึงเริ่มที่ถ้วยหนึ่งใบและจบที่การนึกความหมายของ *cup* หลังเก็บคำ เส้นทางสำเร็จใช้คำและคำแปลที่มีอยู่ในพจนานุกรมของแอป ส่วน *suitcase* จากแบบเดิมใช้สาธิตกรณีขาดคำแปลและการเพิ่มคำด้วยตนเอง

## ทางเข้าและเส้นทางที่กดได้

| งาน | ใน Flutter ปัจจุบัน | ในต้นแบบ |
|---|---|---|
| เริ่มสแกน | เมนูเครื่องมือ → สแกนวัตถุ หรือ ตั้งค่า → สแกนวัตถุเป็นคำศัพท์ ทั้งสองทางไป `practice/object-scanner` เมื่อฟีเจอร์มองเห็นได้ สถานะเริ่มต้นสำหรับภาคสนามคือ `limited` | คลังคำศัพท์ → เพิ่มคำ → ถ่ายภาพสิ่งของ → ลองสแกนถ้วย → อนุญาตในตัวอย่างนี้ → ถ่ายภาพตัวอย่าง |
| เก็บคำ | ผลที่มีคำแปล → เพิ่มเข้าคลัง → บันทึกแล้ว ระบบหาหรือสร้างหมวดจากข้อมูลของคำนั้น | ตรวจคำก่อนเก็บ → เก็บคำว่า cup → เปิดชุดของใช้ในครัว → ลองนึกความหมาย → เปิดคำแปล |
| ปฏิเสธหรือปิดสิทธิ์ถาวร | ขอสิทธิ์เมื่อเริ่มเปิดกล้อง หากปฏิเสธชั่วคราวขอใหม่ได้ หากปิดถาวรเปิด `settings/device-permissions` แล้วไปตั้งค่า Android ศูนย์สิทธิ์อ่านสถานะอีกครั้งเมื่อกลับเข้าแอป | ยังไม่อนุญาต → ขอสิทธิ์อีกครั้ง หรือ เครื่องไม่ขึ้นคำขอสิทธิ์ → ดูสิทธิ์กล้องและไมโครโฟน |
| โมเดลยังไม่พร้อม | ดาวน์โหลด ตรวจไฟล์และเปิดใช้โมเดล แล้วลองเริ่มกล้องใหม่ การยกเลิก ดาวน์โหลดล้มเหลว และไฟล์ที่เสียหายมีข้อความเฉพาะ | ลองสถานการณ์อื่น → ต้องเตรียมกล้องครั้งแรก → ลองดาวน์โหลดในตัวอย่าง → สำเร็จ ยกเลิก หรือดูกรณีไฟล์เสียหาย |
| ภาพอ่านไม่ได้ | หากไม่มีผลผ่านเกณฑ์ แอปแจ้งปัญหา คุณถ่ายภาพใหม่ได้เมื่อกล้องพร้อม | ลองภาพอื่น → ภาพสั่น → ถ่ายใหม่ |
| พบชื่อวัตถุแต่จับคู่คำแปลไม่ได้ | ผลสแกนแสดงชื่อจากโมเดลและปุ่มฟังเสียง การเก็บคำด้วยปุ่มของเครื่องสแกนต้องมีรายการในพจนานุกรม | ลองภาพอื่น → กระเป๋าเดินทาง → พิมพ์คำศัพท์เอง → เก็บในชุดที่ระบุ หรือกลับไปถ่ายชิ้นใหม่ |
| บันทึกหรือออกเสียงไม่ได้ | ยังคงเห็นผลเดิมเมื่อบันทึกล้มเหลว เมื่อระบบอ่านเสียงใช้ไม่ได้จะแสดงข้อความแจ้ง | ลองสถานการณ์อื่น → บันทึกคำไม่สำเร็จ → ลองเก็บคำอีกครั้ง และในหน้าตรวจคำมีทางดูกรณีเสียงยังไม่พร้อม |

ที่มาของทางเข้าและสถานะอุปกรณ์อยู่ใน [เมนูหลัก](../../../lib/screens/main_navigation_screen.dart#L228), [ตั้งค่า](../../../lib/screens/setting_screen.dart#L911), [สถานะเริ่มต้น](../../../lib/runtime/field_feature_registry.dart#L12), [ตัวจัดการสแกน](../../../lib/screens/object_scanner_screen.dart#L92) และ [ศูนย์สิทธิ์](../../../lib/screens/device_permission_center_screen.dart#L111)

## อะไรทำให้ผลจากกล้องกลายเป็นคำศัพท์

1. แอปขอสิทธิ์กล้อง เปิดกล้อง และโหลดโมเดลบนเครื่อง ปุ่มถ่ายภาพเปิดเมื่อทั้งกล้องและโมเดลพร้อม โมเดลที่กำหนดไว้มีขนาด 4,287,874 ไบต์ จึงใช้ข้อความ “ประมาณ 4.3 เมกะไบต์” ในแบบ [ขั้นตอนเปิดกล้อง](../../../lib/features/media_practice/application/object_scanner_use_cases.dart#L111) และ [ข้อมูลโมเดล](../../../lib/features/device_model/domain/model_manifest.dart#L63)
2. ภาพถูกแปลงเป็น RGB ขนาด 224 × 224 โมเดลคืนผลสูงสุด 10 อันดับ ระบบกรองลำดับพื้นหลังและผลที่ความมั่นใจต่ำกว่า 0.15 แล้วหาผลแรกที่จับคู่พจนานุกรมได้ พจนานุกรมเทียบชื่อแบบตรงก่อนจึงเทียบข้อความย่อย ตัวเลข 82% ในตัวอย่างเป็นค่าจำลองของผลภาพเดียว [การจำแนกและกรอง](../../../lib/features/media_practice/application/object_scanner_use_cases.dart#L149) และ [วิธีจับคู่ชื่อ](../../../lib/services/object_vocabulary_database.dart#L31)
3. *Cup* จับคู่กับ “ถ้วย” ในหมวด `Kitchen` ซึ่งต้นแบบแสดงว่า “ของใช้ในครัว” เมื่อกดเก็บ ระบบใช้คำและความหมายที่ปรับรูปข้อความแล้วเพื่อตรวจคำซ้ำภายในหมวด และคืนรายการเดิมเมื่อมีอยู่แล้ว [คำในพจนานุกรม](../../../lib/services/object_vocabulary_database.dart#L1115) และ [การบันทึกคำ](../../../lib/features/media_practice/application/object_scanner_use_cases.dart#L204)
4. ต้นแบบให้เลือกกล้องจากปุ่ม “เพิ่มคำ” ในหน้าคลัง หรือจากปุ่ม “ถ่ายภาพเก็บคำศัพท์” ในชุดครัวที่ยังว่าง ถ้าผลสแกนไม่มีคำแปล ผู้เรียนเปิดฟอร์มพิมพ์คำเองได้ เมื่อบันทึกสำเร็จจึงเปิดบัตรฝึกได้ ใน Flutter ฟอร์มเพิ่มคำรับ `categoryId` จากหน้ารายการคำ ส่วนหน้าสแกนจบด้วยปุ่มสถานะ “บันทึกแล้ว” เมื่อเชื่อมทางเดินใหม่ต้องส่งทั้งหมวดและคำที่เพิ่งเก็บให้ถูกต้อง [หน้ารายการคำ](../../../lib/screens/vocab_list_screen.dart#L207) · [ปุ่มรับผลสแกน](../../../lib/screens/object_scanner_screen.dart#L494)

## ขอบเขตการตรวจ

เดินเส้นทางให้ครบทั้งการพบคำแล้วเก็บเข้าชุด การปิดสิทธิ์ถาวร การเตรียมโมเดลและกู้ไฟล์เสีย การเพิ่มคำเองเมื่อไม่มีคำแปล การถ่ายภาพใหม่ และการกู้ผลเดิมหลังบันทึกล้มเหลว ตรวจทั้งหน้าผลและสถานะที่เห็นเมื่อกลับเข้าคลังในรอบเดียวกัน [เส้นทางกล้อง](camera_routes.py) · [โครงเมนูของต้นแบบ](navigation-design.md)

โค้ด Flutter ยังมีการพักและคืนกล้องตามวงจรแอป การยกเลิกคำสั่งระหว่างจับภาพ และการทดสอบความเร็วโมเดลบนอุปกรณ์จริง ฟีเจอร์ด้านฮาร์ดแวร์เหล่านี้ยังต้องตรวจแยกบนเครื่องจริง ต้นแบบใช้ภาพ ตัวเลข และการอนุญาตจำลอง อ้างอิงชุดทดสอบเดิมที่มีใน repository โดยรอบนี้ตรวจต้นแบบเท่านั้น [ชุดทดสอบหน้าสแกน](../../../test/screens/object_scanner_screen_test.dart) และ [ชุดทดสอบการจับคู่และเก็บคำ](../../../test/features/media_practice/object_scanner_use_cases_test.dart)
