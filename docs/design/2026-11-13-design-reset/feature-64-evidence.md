# 64 รายการของ LexiQuest ตรงกับงานใดบ้าง

แผนงานรวมฉบับวันที่ 13 กันยายน 2026 มี **64 ชุดงาน** ตั้งแต่เตรียมซอร์สจนถึงตรวจรับรุ่น รหัส P0.1–P8.9 ข้อกำหนดอีกฉบับเรียกชุดเดียวกันว่า “44-feature catalog/64-package list” ส่วนบัญชีความสามารถของผลิตภัณฑ์มี 44 รายการใน 8 หมวด ทั้งสองบัญชีเชื่อมกันแบบหลายต่อหลาย เช่น งาน P5.1–P5.3 เกี่ยวกับกล้อง แต่ครอบคลุมตั้งแต่การขอสิทธิ์ การแยกผลที่ยังไม่แน่ใจ จนถึงการเก็บคำ [แผนงานฉบับปรับปรุง](C:/Users/Phet/.codex/worktrees/lexiquest-current/LexiQuest/docs/development/2026-09-13-full-system-work-ledger.json) · [ข้อกำหนดโครงการ](C:/Users/Phet/.codex/worktrees/lexiquest-current/LexiQuest/AGENTS.md) · [รายการความสามารถทั้ง 44 ข้อ](feature-coverage.md)

ทะเบียนวันที่ 13 กันยายนเชื่อมชุดงานกับ 74 รายการ ประกอบด้วยความสามารถ f01–f44 รูปแบบฝึก 14 แบบ เส้นทางผจญภัยและแข่งกับสถิติเดิม 2 เส้นทาง และกลุ่มปฏิสัมพันธ์ MG-01–MG-14 จำนวนรวมนี้อธิบายขอบเขตที่ต้องตรวจ ส่วนคำถามว่าในต้นแบบทำงานใดจบได้ ให้ดูปุ่ม สถานะหลังทำรายการ และปลายทางกลับของงานนั้น [แผนผังระบบและเส้นทาง](system-map.html)

วันที่ 14 กันยายนมีการเพิ่มงานกล้อง P5.3a, P5.3b และ P5.3c เพื่อจัดหมวดหมู่และสิทธิ์ข้อมูล แบ่งชุดภาพ และฝึกกับส่งออกโมเดลที่ทำซ้ำได้ ฉบับปรับปรุงจึงมี 67 ชุดงาน โดยเก็บรหัสเดิมทั้ง 64 ไว้ ตารางด้านล่างยึดฉบับก่อนเพิ่มสามรายการ ตรวจซ้ำใน Git ได้ด้วย `git show 9125ae7b:docs/development/2026-09-13-full-system-work-ledger.json` และเทียบกับ `a97bd9e5` [บันทึกทบทวนแผน](C:/Users/Phet/.codex/worktrees/lexiquest-current/LexiQuest/docs/development/2026-09-13-current-system-and-plan-readiness.md)

ในตารางใช้ชื่อชุดงานตามต้นฉบับ คอลัมน์รหัสอ่านจากช่องอ้างอิงย้อนกลับของทะเบียน 74 รายการ เครื่องหมาย “—” แปลว่าทะเบียนไม่ได้ผูกรหัสโดยตรง ลิงก์ตัวอย่างเปิดสถานะที่เกี่ยวข้องในต้นแบบ ข้อที่ระบุว่าต้องทดสอบบนอุปกรณ์หรือกับข้อมูลจริงต้องมีผลทดสอบเพิ่มเติมก่อนตรวจรับ
