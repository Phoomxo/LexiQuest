**ตรวจว่ากดจบที่ไหน** เปิดผลจากโหมดนำเสนอของ FigCraft ดูชื่อกรณี จำนวนครั้งที่กด ข้อความที่ตรวจพบ และหน้าสุดท้าย ช่อง `figcraft_sha256` ระบุว่าใช้ไฟล์รุ่นใด ถ้าแก้ไฟล์ ให้รันคำสั่งทดสอบด้านล่างอีกครั้ง [หลักฐานการกดใน FigCraft](present-evidence.json)

**ตรวจขอบเขต 64 รายการ** ทะเบียนวันที่ 13 กันยายนระบุ 64 ชุดงาน ตั้งแต่ฝึกคำศัพท์ด้วยกล้องจนถึงทดสอบก่อนออกรุ่น ส่วน TOR ระบุความสามารถของผลิตภัณฑ์ 44 ข้อใน 8 หมวด แต่ละชุดงานอาจเกี่ยวข้องกับหลายข้อ ฉบับวันที่ 14 กันยายนเพิ่มงานข้อมูลภาพและฝึกโมเดลอีก 3 ชุด [เทียบชื่อ รหัส และหลักฐานครบ 64 ข้อ](feature-64-evidence.md) · [ตารางเปิดใน Excel](packages-64.csv) · [ผลเทียบรุ่นตั้งต้นกับ TOR](feature-coverage.md)

ลองแตะ **ฝึกภาษา → ฝึกจากชุดคำ → การเดินทาง** แล้วเลือก “สถานี” เปิด “ดูผลการฝึก” และ “ฝึกคำนี้อีกครั้ง” เพื่อลองใช้คำที่พลาดในประโยค ส่วนงานเก็บศัพท์ ให้เริ่มที่ **คลังคำศัพท์ → เพิ่มคำ** เลือก “ถ่ายภาพสิ่งของ” เพื่อเก็บคำจากภาพ หรือ “นำเข้าจากไฟล์” เพื่อตรวจคำจากตารางก่อนบันทึก [โจทย์ทดลองเก็บคำจากกล้อง](camera-journey.md)

AllTCAS รุ่นสร้างกลับ `ldplayer-1.5.3-arm64/signed-phone-vocab` และ `signed-phone-profile` ใช้แยกคิวทบทวน/ชุดคำและตัวตน/การตั้งค่า ติวดาวใน `24-design/after-390-quiz-feedback.png` และ `after-390-tutor.png` ใช้วางความคืบหน้าก่อนโจทย์และหัวข้อสนทนาเหนือช่องถาม ส่วน LingoTrail `v017-parity-browser/feedback/screen.png` ใช้ตัดสินใจให้คำตอบที่เลือกคงอยู่ตอนเฉลย LexiQuest เพิ่มข้อความแยก “คุณเลือกข้อนี้” กับ “คำตอบที่ถูก” และพาไปฝึกคำเดิมในประโยค ภาพสถานีรถไฟ สมุดคำ และกระเป๋าเดินทางสร้างจากรูปทรงที่แก้ได้ใน FigCraft เอง

## หน้าแรกและคลังคำศัพท์

หน้า “ฝึกภาษา” ให้ผู้เรียนเริ่มที่คำซึ่งถึงเวลาทบทวน หรือเลือกฝึกจากชุดคำ อ่านเรื่อง และเปิดแบบฝึกทั้งหมด หน้า “คลังคำศัพท์” เริ่มจากช่องค้นหา ตามด้วยชุดคำส่วนตัว ปุ่ม “เพิ่มคำ” อยู่ด้านขวาของชื่อหน้าและรวมการพิมพ์ ถ่ายภาพ หรือนำเข้าไฟล์ การฝึกจากข้อความอยู่ที่ ฝึกภาษา → ดูแบบฝึกทั้งหมด → ฝึกจากข้อความของฉัน [ตำแหน่งเมนูและเหตุผล](navigation-design.md)

เมนูหลักใช้ “ฝึกภาษา / คลังคำศัพท์ / ความก้าวหน้า / บัญชี” เมนูและคำสั่งเป็นภาษาไทย คำอังกฤษอยู่ในเนื้อหาการเรียน ชื่อหน้าจบรอบใช้ “ผลการฝึกครั้งนี้” แยกจากภาพรวมระยะยาว ไม่แปลชื่อโมดูลภายในมาเป็นชื่อเมนู

ใช้แถวข้อมูลที่มีแนวจัดวางร่วม การ์ดใช้เฉพาะกลุ่มเนื้อหาที่ต้องแยกความสำคัญ พื้นที่ว่างต้องบอกความสัมพันธ์ ไม่ใช้ช่องว่างหรือการ์ดซ้ำเป็นตัวแทนความเรียบร้อย ขนาดองค์ประกอบในบอร์ดเป็นการศึกษาที่ 390×844 ยังต้องตรวจด้วย production theme, text scaling และหน้าจอจริง

## ทำซ้ำและตรวจสอบ

จากไดเรกทอรีหลักของโครงการบนเครื่อง Windows ที่ติดตั้ง FigCraft Desktop และ CLI 0.18.1 แล้ว สร้างต้นแบบและหน้าตรวจรับก่อนทดสอบทั้งสองช่องทาง

```powershell
python -B -X utf8 docs/design/2026-11-13-design-reset/make_prototype.py
python -B -X utf8 docs/design/2026-11-13-design-reset/test_present.py --whole
python -B -X utf8 docs/design/2026-11-13-design-reset/test_present.py --camera-boundaries
node docs/design/2026-11-13-design-reset/test_walkthrough.mjs
```

คำสั่ง `test_present.py` เขียนรายงานหลังทดสอบครบทุกกรณี ส่วน `test_walkthrough.mjs` เปิดต้นแบบ HTML ด้วย Chrome และ puppeteer-core ในเครื่องเพื่อตรวจทางเดินในเบราว์เซอร์ การสร้างต้นแบบใช้ Pillow ร่วมกับ FigCraft CLI

หากต้องการสร้างบอร์ดศึกษารุ่นแรกและภาพ PNG ใหม่ ให้รัน `python -X utf8 docs/design/2026-11-13-design-reset/build_design_study.py` ตามด้วย `node docs/design/2026-11-13-design-reset/render_design_study.mjs`

เมื่อนำไปทดสอบกับผู้เรียน ให้สังเกตว่าหาคำที่ถึงกำหนดได้เองไหม อธิบายความต่างระหว่าง station กับ platform หลังตอบผิดได้หรือยัง และนำเข้าคำโดยไม่เพิ่มคำซ้ำได้หรือเปล่า บันทึกจุดที่ต้องให้คำใบ้ก่อนปรับแอป Flutter ส่วนการซูมตัวอักษร 200% และ TalkBack ต้องทดสอบบนอุปกรณ์จริง
