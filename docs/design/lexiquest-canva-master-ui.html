19 · Feature access matrix

ทุกฟีเจอร์มีสถานะ เจ้าของ และทางออก

Enabled · Core

  • คลังคำ / หมวด / นำเข้า
  • Quiz / SRS / Weakness
  • Reading / Mastery
  • Achievements / Export

Limited · Explicit entry

  • Object scanner + Camera
  • Speech / Shadowing + Mic
  • AI Tutor + BYOK/Consent
  • Research dashboard · Internal

Hidden until ready

  • Curriculum path without data
  • Co-op / Multiplayer
  • Public league
  • Notes / notification automation

Never inferred

  • Research participation
  • Mastery from XP/streak
  • Certification from practice
  • Cloud upload without authority

Account settings

  • Guest / verified account
  • Change password / sign out
  • Cloud state / local fallback
  • Email action / OTP

Learning settings

  • Theme / large text / motion
  • Audio / TTS / speed
  • Mic and camera rationale
  • Reminder policy when approved

Data settings

  • Research consent / withdraw
  • Export CSV/PDF/Anki
  • Owner isolation / delete
  • Sync status / retry

AI settings

  • Secure API key
  • Provider consent
  • Quota / timeout / offline
  • Clear fallback to local learning
กฎเดียวกันทุกหน้า: Primary action หนึ่งจุด · touch ≥ 48dp · สีไม่ใช่สัญญาณเดียว · system Back ทำงาน · ไม่มี feature เปิดก่อน authority พร้อม
