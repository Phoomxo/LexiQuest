## ผลตรวจ

สถานะ: `FINDINGS` — ไม่พบ P1 และพบ P2 ที่แก้เฉพาะจุดได้ 3 รายการ

1. **A04 ระยะหัวข้อกับฟอร์ม** — เพิ่มช่องว่างก่อนช่องอีเมลเป็น 20dp และคง line-height ภาษาไทย 32/23sp เพื่อไม่ให้สระหรือวรรณยุกต์ชน field label ที่ compact width
2. **A04/A04B เมื่อจอเตี้ยหรือคีย์บอร์ดเปิด** — เปิด vertical scrolling ให้ฟอร์ม และวาง info card เป็นส่วนท้ายที่เลื่อนได้ โดยคง CTA หลักและ Google ไว้ก่อนข้อมูลเสริม
3. **O15 ความหมายของ dismiss/Back** — กำหนดและเขียนกำกับชัดว่า ปิดหน้าต่างหรือกดย้อนกลับเท่ากับ “ไม่เข้าร่วม”; ปุ่มหลักยังเป็น “ไม่เข้าร่วมและเรียนต่อ” ส่วนการยืนยันเข้าร่วมเป็น outline

## ความเสี่ยงที่ยังต้องทดสอบบน runtime

- ระยะเวลาของ ST07 ต้องยาวพอให้ TalkBack อ่านประกาศก่อนเปลี่ยนไป ST08
- ตรวจ focus order, pane transition และ hinge/posture บน emulator/เครื่องจริง
- ตรวจว่า 13sp ใช้เฉพาะ metadata และไม่ได้ใช้กับข้อความที่ต้องอ่านเพื่อตัดสินใจ
- ตรวจ font scale 200% โดยเฉพาะ A04/A04B และ O15
