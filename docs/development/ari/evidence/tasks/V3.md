## V3.2 Protocol — ทุก case NOT_RUN

| Case | ขั้นตอน / expected |
|---|---|
| T01 | บัญชี Free ไทยจริงบนเครื่องจริงแต่ละ platform ที่รองรับ; browser login → native app ไม่มี key/Developer mode/companion |
| T02 | “ช่วยอธิบาย bottle และยกตัวอย่างหนึ่งประโยค”; คำตอบใน native LexiQuest ผ่าน route ที่อนุมัติ ไม่มี mock/ภาพ/เสียง/แก้คะแนน |
| T03 | quota หมดจริงหรือ provider test mechanism ที่รองรับ ไม่จงใจเผา quota; หยุดไม่มี credits/overage/fallback; เก็บ usage/billing แยก simulation |
| T04 | offline ก่อนส่ง/กลาง stream แล้ว reconnect; draft อยู่ ไม่ตอบซ้ำหรือคิดซ้ำจาก retry |
| T05 | A ส่งค้าง → logout → B login → late A reply; ไม่รั่ว reply/history/auth และ reject stale event |
| T06 | local logout แยก provider revoke; วัด propagation และ old authorization ถูกปฏิเสธ; B ไม่กระทบ; ไม่ export token |
| T07 | quota/offline/auth failure ไม่มี paid API/shared credential/credits/alternate provider; ตรวจ network/config และ usage/billing |
| T08 | ผู้เรียนไม่ใช่สายคอม 5 คน connect → bottle → provider revoke; >=4/5 ทำครบเอง |

ก่อน pilot ต้องมี V2 build และ technical readiness T01–T07 พร้อมแก้ blocking defect/retest; มีผู้เรียนจริง/บัญชี/อุปกรณ์/consent และการจัดหาที่ผู้ใช้อนุญาต. ไม่ส่งข้อความหาคนภายนอกในงานนี้.

ใช้คำสั่งงานเดียวกัน สังเกตโดยไม่ทำแทน บันทึกเวลา จุดติดขัด ทุก hint/intervention. Procedural assistance ทำให้ attempt นั้นเป็น assisted; เก็บผลเดิม ไม่เปลี่ยน denominator หรือแทนคนที่ไม่ผ่านเงียบ ๆ. Retest/replacement แยกบันทึก. 0/5 คือยังไม่รัน ไม่ใช่ FAIL/0%/PASS. Pilot วัด usability ไม่ใช่ผลการเรียนรู้.

V3-handoff.json มี T01–T08 และ P01–P05 พร้อม case/status/live-or-simulated/build/device/date/expected/actual/evidence/defect/retest. null = ยังไม่สังเกต ไม่ใช่ศูนย์หรือผ่าน. แยกทุก platform/subcase/run/retest; simulation ไม่แทน real account/provider controls/ผู้เรียนจริง. หยุด case เมื่อข้อมูลรั่ว ค่าใช้จ่ายผิดเงื่อนไข หรือ revoke ไม่ได้ บันทึก defect แก้และ retest. ปกปิดข้อมูล ไม่เก็บ token/password/ข้อมูลวิจัย.

## V3.3 ลำดับต่อยอดและ documentary closure

1. หลักฐานใหม่ official หรือคำยืนยันผู้ให้บริการที่ตรวจสอบได้ ระบุ URL/date/version/applicability ปิด G1–G5 → V1 reassessment. ไม่มีหลักฐานใหม่ไม่วนค้นซ้ำ.
2. เมื่อ entry gate ผ่านเท่านั้น สร้าง V2 หนึ่ง task ใน isolated project worktree จาก accepted SHA; ตรวจ SHA ก่อนเขียน feature/ branch มี application writer เดียว.
3. บัญชี Free จริง → native bottle → T01–T07 และ defect/retest → pilot จริง T08 >=4/5 ทำครบเอง. Live tests อยู่ตรงนี้ ไม่ใช้เป็น prerequisite วนกลับก่อน prototype.
4. หลังมี acceptance evidence จึงวาง production security/hosting cost/operations/distribution; E7 ยังแยกและไม่ปิดจากงานนี้.

คง native LexiQuest, browser เฉพาะ login, Free ไทย, ไม่มี key/Developer mode/companion/paid fallback/โครงการจ่าย inference แทน; Gemini นอก scope. ไม่แก้ source/schema/ตัวระบุ/ศัพท์/ประวัติ ไม่ dispatch G/E ไม่สร้าง subagents/V2/successor. ปล่อย writer และปิด phase ทางเอกสาร ไม่รับรอง feasibility/usability.
