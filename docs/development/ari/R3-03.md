# R3-03 — Jev ledger และ guarded routing

ปิด03.1,03.2 และ03.3 ด้วย explicit deterministic fallback ตาม exit ของ R3.
Ledger จริงย้ายเป็น schema2 โดยรักษาสอง settled requests และ policy/reservation/cost/receipt/result เดิมครบ ยอดรวม $0 ไม่มี pending. สำรอง SQLite ใน LexiQuestDevSecrets และตรวจ integrity พร้อมเปรียบเทียบทุกฟิลด์ก่อน/หลัง.

แยก synthetic/review/routing เป็น fixed batches สูงสุด12ต่อ purpose ภายใต้เงิน free $5 ก้อนเดิม; cache/request identity ผูก purpose/batch/source/schema/policy. ป้องกันเวลา NaN/Infinity, receipt generation ซ้ำ, cache หลุดหลัง migration และ CLI ลง review ผิด batch. Incident policy จำกัด action/attempt/deadline พร้อม veto เรื่อง billing, source, single writer, evidence และ data safety.

ตรวจผ่าน44 offline tests ด้วย verify-scope Targeted/Runtime Resume หลังเห็น RED ของแต่ละการเปลี่ยน. แก้ fixture ปิด SQLite connection บน Windows โดยไม่ลด assertion. Python/CLI dependency closure ตรงกับ receipt หลังแก้เอกสาร จึงไม่รัน gate ซ้ำ. โค้ดแอปและฐาน Vivo ไม่เปลี่ยน.

Route: DETERMINISTIC_FALLBACK, coordinator Astra/medium; ไม่มี Jev call/worker dispatch/เงินจริง. Standard/default เป็น policy ที่ร้องขอ เครื่องมือไม่แสดง runtime tier. Live Choice adapter/สด billing และ eligible shortlist ยัง pending; ไม่อ้าง Jev เลือกหรือประหยัด token. Dispatcher/incident persistence เป็น R3-04.
