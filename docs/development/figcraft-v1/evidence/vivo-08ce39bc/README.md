## ขอบเขตและการเก็บภาพ

ยังไม่ตรวจ TalkBack แบบครบเส้นทาง, ความเข้าใจเสียงอ่าน, กล้องที่รู้ชื่อวัตถุล่วงหน้า, manual form ที่ 200%, landscape และ theme สว่างบน vivo รุ่นนี้. หลักฐาน TalkBack รุ่น `984e6164` ใช้แทนการตรวจ source ใหม่ไม่ได้.

`01-startup-before-first-frame.png` เป็นภาพเริ่มต้นก่อน Flutter วาดเฟรม ส่วน XML จับภายหลัง. เก็บไว้เป็น diagnostic เท่านั้น และตัดสองไฟล์นี้ออกจาก acceptance. Snapshot 02–32 เป็นหลักฐานที่ใช้ข้างต้น. ไม่มีการสร้างภาพ Flutter ด้วย AI หรือแก้ pixels ภาพดิบ.

ใช้ `tool/figcraft/capture_android.py` สำหรับภาพถัดไปได้ โดยเปลี่ยน prefix ทุกครั้งเพื่อรักษาหลักฐานเดิม:

```powershell
python -X utf8 tool/figcraft/capture_android.py DEVICE_SERIAL build/new-capture
```

ตัวช่วยตรวจ PNG signature/ขนาด, XML hierarchy, SHA-256 และปฏิเสธ prefix ที่มีไฟล์แล้ว. Smoke บน vivo ผ่าน และ negative check ยืนยันว่าไฟล์เดิมไม่เปลี่ยน. Manifest ระบุ hash ของทั้ง 64 ไฟล์ รวม diagnostic สองไฟล์ โดยไม่บันทึก persistent USB serial.
