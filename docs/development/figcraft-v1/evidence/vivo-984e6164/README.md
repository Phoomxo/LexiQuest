## เส้นทางสำรองที่ทำจบจริง

1. เปิด A → เพิ่มคำ → นำเข้าจากไฟล์. CSV UTF-8 83 bytes มี header `word,meaning,partOfSpeech`, station/สถานี/noun และ ticket/ตั๋ว/noun ถูก native picker ส่งกลับ แต่แอปปฏิเสธชนิดไฟล์. ดูข้อผิดพลาดด้านล่าง.
2. เปลี่ยนเป็น JSON UTF-8 146 bytes ของสองคำเดียวกัน. Native picker เปิด preview “ผ่าน 2 · ต้องแก้ 0 · ซ้ำ 0”. ตรวจรายการแล้วแตะ **ยืนยันนำเข้า**. กลับ A เห็นสองคำและข้อความ “เพิ่ม 2 · ซ้ำ 0 · ไม่ผ่าน 0”. [ก่อนยืนยัน](29-json-preview.png), [หลังยืนยัน](30-import-confirmed.png).
3. แตะ **ฝึกจากชุดนี้**. ข้อแรกเป็น ticket จงใจแตะ “สถานี” เพื่อทดสอบคำตอบผิด. ข้อสองเป็น station แตะ “สถานี” เพื่อทดสอบคำตอบถูก. ทั้งสองเป็นการแตะตัวเลือกจริงผ่านหน้าฝึก ไม่เขียนผลจากภายนอก. [ข้อแรก](31-question-one.png), [เฉลยผิด](32-feedback-wrong.png), [ข้อสอง](33-question-two.png), [เฉลยถูก](34-feedback-correct.png).
4. แตะ **ดูผลการเรียน** ได้ 50%, ถูก 1, ผิด 1, รวม 2 และคำที่ควรฝึกต่อ ticket. แสดงชื่อ A. [ผลรอบ](35-score.png).
5. แตะ **กลับไปที่ชุดคำ** กลับ A เดิมพร้อม station/สถานี และ ticket/ตั๋ว. [กลับ A](36-back-a.png).

## ข้อผิดพลาด native CSV

เลือก `FigCraft-A-20261114.csv` ผ่าน Android DocumentsUI จาก Downloads แล้วพบข้อความ **“รองรับเฉพาะไฟล์ CSV และ JSON”** แทน preview. [ภาพข้อผิดพลาด](17-import-preview.png).

อ่าน MediaStore เฉพาะไฟล์สังเคราะห์นี้ได้ `_display_name=FigCraft-A-20261114.csv`, `mime_type=text/comma-separated-values`. ชนิดนี้ไม่อยู่ใน allowlist ของ parser รุ่นที่ติดตั้ง. JSON ทางเลือกผ่านตามเส้นทางข้างต้น. ผู้พัฒนาได้รับข้อมูลนี้เพื่อแก้และทดสอบใหม่ใน APK ถัดไปแล้ว. รอบนี้ไม่แก้ APK หรือ bypass validation บนเครื่อง.
