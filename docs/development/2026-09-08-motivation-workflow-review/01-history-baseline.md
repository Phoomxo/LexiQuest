## Workflow ที่ต้องให้ทุกฝ่ายตรวจร่วมกัน

1. ผู้เรียนเปิด Learn หรือทางเข้าเดิม → เลือกกิจกรรม/เรียนต่อ → ตั้งค่าที่ข้ามรายละเอียดได้ → session เดิม
2. คำตอบหลัก → canonical learning commit → projection ของ review/mastery/quest/reward ตาม eligibility เดิม → feedback/result/history
3. Cloze ที่บันทึกแล้ว → optional ฟัง/ลองพูด/ข้าม → ข้อต่อไปหรือปิด session เดิม; ไม่มี learning/reward/research delta จากแผงพูด
4. Today และ Adventure อ่านงานค้าง/review/recommendation/ผลเดิม; ต้องรักษา gates, unavailable states และ owner transition
5. การเลือก/ซื้ออุปกรณ์ผ่าน reward authority; preview หรือเปิดผลซ้ำต้องไม่ซื้อหรือให้รางวัลใหม่
6. Research มีเส้นทางแยกที่ต้องสมัครใจและผ่าน authority; คนไม่ร่วมต้องผ่านข้อ 1–5 ได้โดยไม่มี collection/upload เพิ่ม
