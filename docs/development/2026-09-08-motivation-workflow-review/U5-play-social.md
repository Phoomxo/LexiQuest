วันที่ 8 กันยายน 2026; มุมมองจำลองเพื่อท้าทายการออกแบบ ไม่ใช่เสียงเด็กจริง การสัมภาษณ์ หรือ UAT
ตรวจ working tree `C:/Users/Phet/.codex/worktrees/02fa/LexiQuest` บน `codex/pair-matching-pm0-pm8` รวมงานที่ยังไม่ commit
บทบาทนี้ให้ความสำคัญกับความอยากลอง ความเป็นตัวเอง และเพื่อนที่ไว้ใจ; ไม่สมมติว่าเด็กไทยทุกคนชอบเกมหรือแข่งขัน
เป้าหมายคือช่วยให้เด็กเข้าถึงการเรียนที่อยากทำ; รายได้ไม่ใช่เหตุผลให้เพิ่มแรงกดดัน การสะสม หรือการชวนเพื่อน

## จุดยืน

เห็นด้วยกับ P1–P4 เมื่อช่วยให้เริ่มและเห็นความหมาย แต่ไม่เห็นด้วยกับลำดับที่รอให้แผนรายสัปดาห์ครบก่อนจึงทำความสนุก
P5 แบบเล็กที่มองเห็นของที่ใส่จริงควรทำขนานกับการลดขั้นตอน P1: ร้านค้าปัจจุบันสร้างความคาดหวังที่ภาพยังตอบไม่ได้ [S1]
P3 ควรให้เลือกกิจกรรมที่สนใจจริง ไม่เปลี่ยนโจทย์ “ตอบถูกให้ครบ” เป็นชื่อเรื่องน่ารักแล้วเรียกว่ามีทางเลือก
P6 มีคุณค่าที่ควรพิจารณาเรื่องการอยู่ร่วมกับเพื่อน แต่เป็นขอบเขตใหม่ ต้องออกแบบแยกจากการจบ Adventure ระยะแรก [S7]
ความชอบ สนุก กลับมาใช้ และเรียนดีขึ้นเป็นคนละข้ออ้าง; รายงานนี้ยังพิสูจน์ข้อใดด้วยข้อมูลผู้เรียนไม่ได้

## ปัจจุบัน → เส้นทางที่เสนอ

ปัจจุบัน: Learn/ทางเข้าเดิม → เลือกกิจกรรม → คำตอบบันทึกผ่านระบบเดิม → ผล/ประวัติ → ภารกิจและรางวัลตามสิทธิ์
ใน build ที่เปิด Adventure: ภารกิจหลักวันนี้ → ตัวช่วย → แผนที่; มีสวิตช์กลับ Standard และ mission เป็น resume/review/recommendation [S3]
การแต่งตัว: ร้านค้าดูยอด/เลเวล → ซื้อหรือเลือกใช้ → ใน Adventure เห็นชื่อของบน chip ไม่ใช่ภาพที่สวม [S1, S2]
ภารกิจใน catalog ที่ตรวจเป็นตอบถูก 5 ครั้งรายวันและ 20 ครั้งรายสัปดาห์ มี XP และเวลาหมดอายุ; หน้าปัจจุบันแปลไทยแล้ว [S4]
ประวัติ Pair แยกทำเอง/ใช้ตัวช่วย และบอกตรงว่าฝึกซ้ำไม่เพิ่มความก้าวหน้าหรือรางวัล [S5]
ข้อเสนอ: เปิด → เริ่ม/เรียนต่อได้ทันที หรือเลือก “วันนี้อยากลองอะไร” จากตัวเลือกสั้นที่เชื่อมโหมดเดิม → เล่นหนึ่งรอบ
หลังบันทึก: เห็นสิ่งที่ทำได้จริงหนึ่งเรื่อง + เลือกแต่งตัวจากของที่มี/จบรอบ/เรียนต่อ; ไม่บังคับวนกลับไปเก็บรางวัล
เป้าหมายและสัปดาห์เป็นเครื่องช่วยที่เปิดเมื่อต้องการ; วันสำรวจเล่นได้โดยไม่ต้องตั้งเส้นตายหรือยอมรับแผนก่อน [S6]
อนาคตเมื่อ P6 ผ่านการตัดสินใจ: เลือกฝึกกับเพื่อนที่รู้จัก → แต่ละคนเลือกงานและจังหวะตนเอง → ส่งกำลังใจแบบจำกัดและออกได้
คำว่า “ร่วมกัน” หมายถึงสนับสนุนกัน ไม่กำหนดว่าต้องมีอันดับ คะแนนร่วม หรือโทษเมื่ออีกคนไม่มา

## ผลกระทบและข้อขัดแย้งสำคัญ 3 เรื่อง

1. P1/P2 ↔ ความอยากสำรวจ: ถ้าก่อนเล่นต้องเลือกเป้าหมาย ตาราง และเห็นงานค้างหลายชุด หน้าเปิดจะคล้ายการบ้าน
   ผลจริงต่อเส้นทาง: CTA เริ่มรอบเดิมอาจถูกแผนเลื่อนลง; เด็กที่อยากลองหัวข้อใหม่ต้องต่อรองกับแอปก่อนเริ่ม
   ประโยชน์ P1 คือช่วยเด็กที่อยากมีโครงสร้าง; จึงเก็บทางลัดแผนไว้ แต่ให้เริ่มก่อนและปรับ/ข้ามแผนโดยไม่เสียสิทธิ์
   P2 ใช้ประวัติและ Mastery เดิมอย่างซื่อตรง; บอก “รอบนี้ทำเองได้...” ไม่แปลง XP/ชุดเกราะเป็นความเก่งภาษา [S5, S7]

2. P3/P5 ↔ ระบบรางวัลเดิม: ภารกิจตอบถูกซ้ำและรางวัลเป็นข้อความอาจทำให้คำสัญญาเรื่องเกมไม่เกิดในประสบการณ์
   ผลจริงต่อเส้นทาง: เด็กใช้เหรียญแล้วไม่เห็นรูปลักษณ์เปลี่ยน จึงแยกไม่ออกระหว่างซื้อสำเร็จกับฟีเจอร์ยังไม่รองรับ
   P5 ควรเริ่มจากภาพอวาตาร์+ของที่ถือครองในพื้นที่ชัดเจนหนึ่งแห่ง พร้อม preview ที่ไม่มีการซื้อและภาพสำรอง [S1, S2]
   ไม่ใช้ยอดซื้อ เวลาค้างในร้าน หรือการรีบสะสมเป็นเป้าสำเร็จ; ไม่เพิ่มเหรียญหรือแต้มมิตรภาพเพื่อทำให้ภาพดูมีคุณค่า
   P3 เริ่มด้วยตัวเลือกงานจากเหตุผล/โหมดเดิม; การเพิ่มชนิด quest/objective/reward ต้องผ่าน authority และ catalog version เดิม [S4]
   หากเด็กเลือกงานใหม่ทั้งที่มี review ค้าง ให้เห็นเหตุผลของ review และเลือกกลับได้; อย่าแอบนับทางเลือกเป็นการทำ review แล้ว

3. P4/P6 ↔ ความเป็นเพื่อนและแรงกดดัน: เพื่อนช่วยให้กล้าลองได้ แต่ภารกิจร่วมแบบ “ขาดเธอทีมแพ้” ทำให้การพักมีต้นทุนทางสังคม
   ผลจริงต่อเส้นทาง: เด็กอาจเปิดแอปเพื่อไม่ทำให้เพื่อนผิดหวัง แม้ตัวเลขกลับมาใช้ดีขึ้นแต่ประสบการณ์แย่ลง
   เสนอการร่วมฝึกแบบต่างคนต่างจังหวะ ไม่โชว์ว่าใครทำน้อย/ขาดเรียน/อ่านช้า และไม่ย้ายการเตือนจากตัวเด็กไปให้เพื่อน
   เก็บ P4 “พักแล้วกลับได้” และ companion ที่สนับสนุน; generic companion ยังเป็นข้อความอังกฤษ ต่างจาก Adventure ที่เลือกภาษาได้ [S8]
   P6 ไม่ใช่เปิด flag Adventure เพิ่มหนึ่งตัว: แผนเดิมตัด friend/room/chat ออก และ field defaults ยังซ่อน Adventure [S7, S9]

## จุดประนีประนอมและลำดับส่งมอบ

ระยะ A: P1 ลดภาระเริ่ม + P2 ข้อสรุปจริงหนึ่งรายการ; P5 ภาพของที่ใส่ทำควบคู่เมื่อแยกงานและตรวจได้ ตามข้อทักท้วง PM ด้านการส่งมอบ
ระยะ B: P3 ทางเลือกกิจกรรมจำนวนจำกัด + P4 กลับมาอย่างเบาใจ; เริ่มจากการเชื่อมของเดิมก่อนเพิ่มเงื่อนไข quest
ระยะ C: ตัดสินปัญหาและขอบเขต P6 แยกต่างหาก; ยังไม่สร้าง friend graph, ห้อง, chat, leaderboard หรือเปิด enrollment
ไม่บังคับใช้ทุก P พร้อมกัน และไม่ตัด P5 เป็น “ของประดับภายหลัง” โดยไม่มีการชั่งผลจากความคาดหวังเดิมในร้าน
ต้นแบบ P6 รอบนี้ทำเป็นสถานการณ์กระดาษ/ข้อมูลสังเคราะห์ได้ โดยไม่มีบัญชีเด็ก เพื่อนจริง หรือการส่งข้อมูลออก
ความยั่งยืนหมายถึงภาระภาพ/อุปกรณ์/การดูแลที่โครงการรักษาได้; เริ่มฉากและชุดจำกัด ไม่ตั้งระบบหารายได้ก่อนเห็นปัญหาจริง

## ความสมัครใจ ความเป็นส่วนตัว และสิทธิ์หยุด

ข้อเสนอพฤติกรรมเท่านั้น รอบนี้ไม่เก็บข้อมูลหรือเปลี่ยน policy ใด: ผู้เล่นคนเดียวได้เส้นทางเรียนและสิทธิ์รางวัลเท่าเดิม
P6 ในอนาคตต้องเลือกเข้าร่วมเอง ไม่ดึงสมุดรายชื่อ ไม่ค้นหาตามโรงเรียน/ตำแหน่ง ไม่เผยคะแนน ประวัติ หรือการไม่เข้าเรียน
ใช้ตัวตนแสดงผลที่ไม่จำเป็นต้องเป็นชื่อจริง; ปฏิเสธ/ออก/ปิดการชวนได้โดยไม่มีคำตำหนิ รางวัลลด หรือแจ้งเหตุผลให้เพื่อน
ไม่ตั้งรางวัลจากจำนวนชวนเพื่อน ไม่ออกแบบวัตถุจำกัดเวลาเพื่อเร่งเด็ก และไม่ผูก cosmetic กับความสนิทหรือความนิยม
เสียงเสริมหลัง cloze เป็นการลองชั่วคราว; ห้ามเปลี่ยนเป็น quest “อัดเสียงให้เพื่อน” หรือหลักฐาน speech/mastery ผ่าน P3/P6 [S10]
หากอนาคตต้องมีข้อมูล owner-scoped ใหม่ ต้องตัดสินวงจรข้อมูลและการเข้าถึงก่อน implementation; ไม่จอง migration ใน memo นี้

## Acceptance cases ที่เสนอให้ตรวจภายหลัง

AC1 — เด็กเลือกสำรวจ ไม่ตั้งแผน: จากหน้าเปิดเข้ากิจกรรมเดิมได้โดยไม่กรอก goal/deadline; เลือกจบรอบได้และผลเรียนยังบันทึกปกติ
เกณฑ์สำคัญ: ไม่มีบทลงโทษ/ยึดของ/ลด mastery เพราะข้ามแผน; review ที่ค้างยังแสดงตามจริง ไม่ถูกแผนใหม่กลบ
AC2 — เด็กแต่งตัวออฟไลน์: ของที่เป็นเจ้าของและเลือกใช้แสดงถูก slot; preview/เปิดซ้ำ/retry/สลับ owner ไม่ซื้อหรือเพิ่มรางวัลซ้ำ
เกณฑ์สำคัญ: ภาพหายยังมีชื่อและกลับเรียนได้; ไม่มีภาพจาก owner ก่อนหน้า; การซื้อที่ยังยืนยันไม่ได้ไม่แสดงว่าได้รับแน่นอน
AC3 — เด็กไม่อยากร่วม/เพื่อนพัก: ปฏิเสธหรือออกจากต้นแบบ co-op แล้วยังเริ่ม solo ได้; ไม่มีข้อความบอกว่าเป็นเหตุให้ทีมเสียรางวัล
เกณฑ์สำคัญ: สถานการณ์สังเคราะห์ไม่ส่งข้อมูล/แจ้งเตือนจริง และความผิด/ความเร็ว/การเว้นช่วงของแต่ละคนไม่ถูกเผยต่อเพื่อน
ทั้งสามเป็นเกณฑ์อนาคต ไม่ใช่ผลทดสอบรอบนี้; automated tests เดิมไม่ตอบว่าเด็กรู้สึกสนุกหรือเป็นส่วนหนึ่งจริง [S10]
