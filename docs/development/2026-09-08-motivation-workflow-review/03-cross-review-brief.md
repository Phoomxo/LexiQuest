# รอบโต้แย้งและทบทวนข้อสรุป

Initial memos ของ U1–U5, BA, PM, SA, DEV, QA จัดทำครบแล้ว รอบนี้แต่ละบทบาทต้องอ่านข้อโต้แย้งและสรุปการยอมรับ/ปรับ/คัดค้านในไฟล์ของตนเอง ก่อน S11 รวบรวมและตัดสิน ไม่ใช้จำนวนผู้เห็นด้วยแทนหลักฐาน

## ข้อมูลเพิ่มเติมที่ทุกฝ่ายต้องรับ

- อ่าน `00-review-brief.md` ส่วน user clarifications: ปัญหาเด็กไทยมาก่อนรายได้ และ UX/UI ต้องสวยงาม ใช้รูปแบบที่คุ้นเคยจาก Duolingo/ALLTCAS
- อ่าน `02-design-evidence.md`: root เปิดดูภาพ Learn, shop, cloze และ large text เดิมจริง มี design alternatives, screen requirements, theory limits และ acceptance candidates
- BA รายงาน5แหล่งสาธารณะ แยกข้อมูลระดับครัวเรือน/ประชากร/โรงเรียนเฉพาะจากเสียงของเด็กจริง การขอระบุกลุ่มอายุหลักยังไม่มีคำตอบ; ห้ามอ้างเป็นอายุที่ผู้ใช้อนุมัติ
- รายงานทุกไฟล์เป็น analysis/docs-only; source baselineเดิม1472ไฟล์ยังต้องตรวจท้ายรอบ ไม่มี implementation/test/UAT ใหม่

## งานรายบทบาท

แต่ละคนอ่าน peer memos ที่ระบุและเพิ่มหัวข้อ “Cross-review และข้อสรุปหลังโต้แย้ง” 15–25 บรรทัดในไฟล์ตนเอง ระบุข้อเห็นต่างจริงอย่างน้อย2ข้อพร้อมชื่อ peer, สิ่งที่ยอมเปลี่ยน, สิ่งที่ไม่ยอมแลก, ขอบเขตแรกที่ยอมรับ และ acceptance ที่ควรชี้ขาด ถ้าจำเป็นให้แก้ข้อความก่อนหน้าที่ขัดข้อสรุปโดยระบุเหตุผล ไม่ใส่ placeholder/รอไว้ในไฟล์ฉบับสุดท้าย
