# Motivation — Phase B/C decisions and learner validation

สถานะ: ข้อสรุปการตัดสินใจสำหรับงานถัดจาก Phase A ตามแผนที่ผู้ใช้อนุมัติ วันที่ 8 กันยายน 2026 ไม่ใช่การอ้างว่าฟีเจอร์เหล่านี้ติดตั้งแล้วหรือมีผลต่อแรงจูงใจที่พิสูจน์แล้ว

อ้างอิง `docs/superpowers/plans/2026-09-08-motivation-workflow-evolution.md` และรายงานสิบมุมมองพร้อม S11 ใน `docs/development/2026-09-08-motivation-workflow-review/` โครงการแก้ปัญหาผู้เรียนเป็นหลัก การต่อยอดเชิงธุรกิจต้องรักษาสิทธิ์การเรียนและการไม่ร่วมวิจัย

## ข้อสรุปที่จะใช้หลัง Phase A

| Package | Decision | ขอบเขตที่ต้องตกลงก่อนเริ่ม code |
| --- | --- | --- |
| B1 เป้าหมายกับแผนรายสัปดาห์ | ยังไม่เพิ่ม persistent plan; ใช้เป้าหมายและรายการวันนี้ที่อ่านจากข้อมูลจริง แล้วตรวจว่าผู้เรียนยังเชื่อมสองส่วนนี้ไม่ได้หรือไม่ | การจับคู่เป้าหมายกับชุดเนื้อหาต้องมาจากผู้เรียนยืนยัน ระบุ content ID/revision/coverage, งบเวลาประมาณ, revision, แก้/ข้าม/วางใหม่/conflict/freshness; resume และคิวทบทวนยังมีสิทธิ์เดิม ห้ามเดาวิชา/ระดับสอบจากชื่อเป้าหมาย |
| B2 เตือนซ้ำ | เก็บ A2 เป็นการเตือนครั้งเดียวที่เลือกเอง การเตือนวนซ้ำเป็นสัญญาคนละรุ่น | timezone, DST gap/fold, weekday/exceptions, occurrence identity, ยกเลิกทั้งหมด, owner switch, offline/reconcile กับ OS และพฤติกรรมหลังแก้กำหนด ต้องแยก deadline ออกจาก recurrence |
| B3 ภารกิจหลากหลาย | ใช้ Quest catalog v1/รางวัลเดิมก่อน รับฟังว่าตัวเลือกงานช่วยให้กลับมาเรียนหรือเพิ่มภาระ | catalog version, instance pins, assignment time, eligibility, opt-in/swap/expiry/receipt/rebuild; ไม่ย้อนไปแก้ instance เก่าและไม่ให้เครดิต optional voice/replay เป็นคำตอบใหม่ |
| C การเรียนกับเพื่อน | เริ่มประเมินสถานการณ์สังเคราะห์และคุณค่าการช่วยกัน ยังไม่เพิ่ม online social | ต้องตัดสินใจ capability/version/no-social และผลต่อ 8/44, identity/invite/accept/block/visibility/leave/retention/offline/abuse support/cost; ผู้ไม่ใช้สังคมเรียนต่อได้ครบ ไม่เปิด contacts/chat/ranking/shared streak โดยปริยาย |

เหตุผล: สิ่งที่ตรวจพบแน่ชัดใน Phase A เป็นปัญหาการค้นพบทางกด ภาษา การแสดงข้อมูลและความปลอดภัยของการเปลี่ยนผู้เรียน ยังไม่มีการรับฟังจริงที่เพียงพอให้เลือกเพิ่มโครงสร้างข้อมูลรายสัปดาห์หรือระบบออนไลน์ การไม่เพิ่มสองส่วนนี้ในรอบนี้ไม่ทำให้เส้นทางเรียนเดิมสูญเสียสิทธิ์

เมื่อเลือก B ใดไปพัฒนา ต้องตรวจ schema/ledger ที่ใช้งานในขณะนั้นอีกครั้ง (baseline รอบนี้ v24/48 tables) แล้วออก spec และ implementation plan แยก พร้อม migration, guest upgrade, deletion/export, sync conflict/policy/tombstone และ rollback แบบเดินหน้า ไม่จอง migration ในเอกสารนี้และไม่แก้ EvidenceContext/EventEnvelopeV2 เพื่อความสะดวกของ UI

## D1 แบบนำการรับฟังที่พร้อมใช้ แต่ยังไม่เก็บข้อมูลจริง

แยกกลุ่ม ป.4–ป.6 กับมัธยม และครู/ผู้ดูแล; จำนวนเสนอเด็ก 8–12 ครู 3–4 ผู้ดูแล 3–4 เป็นการรับฟังเชิงคุณภาพ ไม่ใช่ตัวแทนประชากร เริ่มกิจกรรมกับผู้ที่ยินยอม/assent ตามกิจกรรมเท่านั้น ไม่ผูกคำตอบกับรางวัล ไม่สร้าง research row หรือ upload จากแบบนำนี้

1. ให้เล่าครั้งล่าสุดที่เรียนภาษาอังกฤษแล้วติดขัด และครั้งที่อยากกลับไปเรียนเอง ก่อนแสดงแอป
2. ให้หาทางเริ่มเรียน เลือกกิจกรรม เปลี่ยนคำตอบ อ่านผล และกลับไปเรียนต่อ โดยไม่ชี้ปุ่ม บันทึกการช่วยเหลือและจุดลังเลแยกจากการตีความของผู้สังเกต
3. ให้ตั้งเป้าหมายและเวลาเตือน อธิบายวันที่/ปี/เขตเวลา เวลาที่เลือกกับเวลาหลังช่วงงดเตือน แล้วปิดการเตือน
4. ให้ลองหมวกโดยไม่ซื้อ อธิบายว่าเหรียญเปลี่ยนหรือยัง จากนั้นยกเลิกการลองและหาของที่สวมจริง
5. ให้ตีความจำนวนตอบถูกหนึ่งข้อ/หลายข้อ/ไม่มีข้อมูล และข้อความกลับมาเรียนหลังพัก ตรวจว่ามีใครเข้าใจผิดว่าเป็นผลสอบ ความสามารถทั้งหมด หรือการเปรียบเทียบก่อน–หลัง
6. สลับลำดับ baseline/prototype ระหว่างผู้เข้าร่วม ถามสิ่งที่สับสนและสิ่งที่ชอบน้อยที่สุด เก็บกรณีค้านไว้ด้วย ไม่ใช้เสียงส่วนใหญ่กลบปัญหาของผู้เรียนที่อ่านช้าหรือไม่ชอบเกม

เกณฑ์รับฟัง: เข้าใจว่ากดอะไรต่อ, แยก preview/ซื้อได้, แยกเวลาที่เลือก/เวลาที่ตั้งจริงได้, เห็นว่าพักและกลับมาได้ รวมทั้งความอยากเรียนต่อ ความรู้สึกทำได้ อิสระในการเลือก และความรู้สึกได้รับการสนับสนุน บันทึกแยกกัน ไม่รวมเป็นคะแนนใหม่โดยไม่มีเครื่องมือและ scoring ที่เหมาะสม

## C สถานการณ์สังเคราะห์สำหรับตัดสินใจ

- เพื่อนตอบรับ: ทั้งคู่เข้าใจงานร่วมและสิทธิ์เห็นข้อมูลก่อนเริ่มหรือไม่
- เพื่อนไม่มา/ปฏิเสธ: ผู้เรียนคนเดียวยังทำกิจกรรมและรับผลตามสิทธิ์เดิม ไม่เสีย streak หรือถูกลงโทษ
- ออกจากกลุ่ม/เปลี่ยนผู้เรียน/ออฟไลน์: ไม่คงสิทธิ์เห็นข้อมูลของคนเดิม ไม่สร้างคำเชิญซ้ำหรือเครดิตซ้ำจาก retry
- เลือกใช้คนเดียวตั้งแต่ต้น: เส้นทางเรียนมีคุณค่าครบ และไม่มีข้อความบังคับเปิดระบบสังคม

ข้อเสนอความยั่งยืนในอนาคต: ประเมินต้นทุนดูแลเนื้อหา เสียง/AI และการช่วยเหลือผู้ใช้ก่อนเลือกรูปแบบสนับสนุนจากสถานศึกษาหรือทุน อย่าสมมติว่าจะต้องเก็บค่าสมาชิก ขายข้อมูลเด็ก หรือทำให้รางวัลกดดันเพื่อเพิ่มเวลาใช้งาน

ผลการทดสอบซอฟต์แวร์ยืนยันกลไกและความถูกต้องของระบบเท่านั้น การยืนยันแรงจูงใจ พฤติกรรมกลับมาใช้ และผลการเรียนต้องใช้หลักฐานคนละชุด บทนำการรับฟังและสถานการณ์สังเคราะห์ข้างต้นยังไม่ใช่ UAT หรือผลการศึกษาจริง
