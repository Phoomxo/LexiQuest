# S01 — ชุดร่างส่งตรวจ r1

สถานะ DRAFT_UNREVIEWED ไม่ใช่บทเรียนที่รับรองแล้ว ไม่ใช้ทดลองผลเรียน. ยังไม่ได้ส่งข้อความหาผู้ตรวจหรือบุคคลภายนอก. Source: `pilot-content-r1.json`; แผนข้อ 5.4, 6.6, 14 และ 15.5.

## รายการที่ผู้ตรวจต้องตัดสิน

1. ผู้ตรวจการสอนอ่าน/ผู้ใหญ่ไทย: เลือกหรือแก้ชุด m/a/s/t/p/i/n, ลำดับสาธิต เสียงต่อเนื่องและเสียงหยุด; แยกชื่ออักษรกับเสียงจริง. ยืนยันคำใหม่ทุกคำใช้เฉพาะ mapping ที่สอน และความหมายเหมาะกับผู้ใหญ่ไทย.
2. ผู้ตรวจภาษา/เสียง: ตรวจเสียงย่อย คำ และเรื่องจากไฟล์จริงทุกชิ้น ระบุสำเนียง เสียงถูกตัด/มีสระแทรก ความดัง อัตรา/ช่องว่าง; ลง path/hash/revision/rights จริง. มีเสียงเรื่องร่างสี่ไฟล์จาก Microsoft Zira Desktop แบบ offline (rate -2) สำหรับฟังตรวจในเครื่องเท่านั้น สิทธิ์แจกจ่ายยัง UNCONFIRMED. ไม่มีเสียง Phonics ที่ผลิต/ตรวจแล้ว.
3. ตรวจ form ก่อน/หลัง/ติดตาม: draft Phonics แต่ละชุดมี CVC /æ/ และ /ɪ/ อย่างละคำ และเรื่องทุกชุดมีการแก้คำขอด้วยประโยคปฏิเสธแล้ว แต่ศัพท์/ทิศทาง/ความคุ้นเคยต่างกันและยังไม่ calibrated; ผู้ตรวจต้องยืนยันว่าเทียบเป้าหมายได้ก่อนใช้ ห้ามอ้างคะแนนพัฒนาการจาก draft นี้.
4. Pin rubric/accepted variants/support policy ก่อนรับคำตอบใด ๆ. เสียงคนไทยที่สื่อคำได้ไม่จำเป็นต้องเหมือนต้นแบบ; ให้ผู้ตรวจนิยามขอบเขต ไม่ให้ ASR เป็นผู้ตัดสินลำพัง. คำตอบความเข้าใจตอบไทย/ถอดความได้ ไม่วัดความสามารถเขียนอังกฤษโดยไม่ตั้งใจ.
5. ภาพในเรื่องต้องเป็นบริบทไม่เฉลยรายละเอียด. รูป/คำแปล/เสียงเฉลยคำก่อนงานอ่านทำให้ผลเป็น assisted. Screen reader ที่อ่านเป้าหมายต้องบันทึกข้อจำกัด claim แต่ยังเรียนต่อได้.

## ใบรับตรวจที่ยังว่าง

ทุกชิ้นต้องมี artifact ID/revision/hash, ผู้ทำจริง/บทบาท/วันที่, finding, correction revision, decision (`APPROVED_FOR_TRIAL`, `CHANGES_REQUIRED`, `NOT_REVIEWED`) และเหตุผล. ขณะนี้ผู้ตรวจ วันที่ ลายรับรอง และผลอนุมัติทั้งหมดเป็น null/ไม่มี ห้ามเติมตัวอย่างชื่อเป็นผลจริง. เปลี่ยนเนื้อหาหรือสื่อหลังอนุมัติต้องตรวจ revision ใหม่.

## บทดำเนินกิจกรรมเมื่อ gate พร้อม

แยกกลุ่ม A ผู้ใหญ่เริ่มศูนย์และ B รู้ชื่ออักษรแต่ยังผสมไม่ได้ตามข้อ 6.6. เปิดด้วย “เลือกฟังเรื่องหรืออ่านคำสั้นได้ ไม่จำเป็นต้องเปิดไมค์ ถ้าข้ามหรือพักก็ไม่ถูกนับว่าผิด”. ตรวจความพร้อมและเงื่อนไขการเก็บข้อมูลรายบุคคลก่อนเริ่มจริง ไม่เก็บเสียงโดยปริยาย; ผู้ตรวจฟังตรงหน้าได้ถ้าผู้เข้าร่วมยินยอม.

งานก่อนเรียน → สาธิต/ฝึกพร้อมตัวช่วย → งานใหม่หลังเรียน → งานใหม่ติดตาม 3–7 วัน. Assessment items ไม่อยู่ในหน้าฝึกของต้นแบบ. ไม่สอนเฉลยข้อหลัง/ติดตามก่อนใช้งาน ไม่ฝึกวนจนผ่านแล้วแทนคำตอบแรก. คนทำได้ก่อนเรียนระบุ ceiling; ขาดนัดคง missing ใน denominator.

บันทึกต่อ attempt: รหัสผู้เข้าร่วมแบบไม่ระบุตัวตน/กลุ่ม/track, วันเวลา, content/media/rule revision, item/family, modality, response จริง, first response, support และผู้ช่วย, rubric outcome, invalid reason, observed-by จริง, self-report แยก, consent scope และการฝึกอื่นระหว่างวัน. บันทึก start/help/skip/pause/resume success/เหตุเลิกและเวลาจริงแยกจากผลเรียน. ไม่มีข้อมูลทดลองใดในชุดนี้.

ตัดสิน track×group แยก: อย่างน้อยสามคนต่อกลุ่ม และหลักฐานงานใหม่/ติดตามอย่างน้อยสองคนพร้อม n/N ทุกคนตามแผน; ไม่ใช้ขั้นต่ำนี้รับรองประชากร. ข้อสอนผิด ข้อมูลหาย/ข้ามเจ้าของ เริ่ม/กลับไม่ได้ หรือผลลวงต้องแก้ก่อน. สองคนติดเรื่องเดียวกันให้แก้ทีละปัจจัย. สองรอบยังติดรูปแบบเดิมให้ทบทวนวิธี/สมมติฐาน ไม่ลด rubric. ยังไม่ลง instructional Flutter จน relevant evidence ผ่าน.

## สื่อที่พร้อมใช้ตอนนี้

มีข้อความร่าง คำสั่งไทย ลำดับสาธิต rubric ข้อใหม่ ภาพ SVG ต้นฉบับสองภาพและเสียงเรื่องร่างสี่ไฟล์ใน `media/` พร้อม path/hash/script hash ใน ledger. ตรวจเฉพาะโครงสร้าง WAV/XML แล้ว ยังไม่รับรองคุณภาพเสียง/ภาพหรือสิทธิ์แจกจ่ายเสียง. ภาพร้านไม่มีเครื่องดื่มเฉลยคำตอบ; ภาพ mat/sit ใช้หลังสาธิตเท่านั้น. สื่อเหล่านี้ยัง PRODUCED_UNREVIEWED; เสียง Phonics ยัง NOT_PRODUCED. ต้นแบบไม่เล่นสื่อร่างเพื่อสอน ใช้ป้ายไม่มีสื่อที่ผ่านตรวจเพื่อทดสอบทางเดินเท่านั้น ไม่มีผลเรียนหรือคะแนนจำลอง.
