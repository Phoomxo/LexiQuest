Credential controllers live inside the dialog and are disposed with it, preventing use-after-disposal during exit animations.

Validation and known reauthentication failures preserve editable fields with Thai guidance and require another explicit Save. Success and uncertain acknowledgement clear credential fields. Uncertainty explicitly says the password may already have changed, closes the submission path and directs the user to separately check sign-in through the existing account flow.
