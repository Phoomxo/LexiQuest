## Verified behavior

- Drift schema 1 upgrades to schema 2 without losing local or outbox rows.
- A leased, deterministic outbox coalesces consecutive local revisions and
  reclaims expired work.
- Push operations use immutable operation acknowledgements and exact base
  revisions; replay does not duplicate cloud entities.
- Pull cursors include both server timestamp and document ID and advance only
  after a complete local transaction.
- Push and pull conflicts retain privacy-safe local/cloud snapshots.
- The Firestore field schema denies cross-user access, malformed payloads,
  revision regression, non-atomic entity writes, and mutable acknowledgements.
- Guest upgrade inventories all 14 owner-scoped tables, remaps dependent rows
  on collisions, rolls back on failure, and preserves account data on logout.
- Build, cached remote, foreground, and background policy paths all fail closed
  for cloud work without blocking local vocabulary.
- Android WorkManager registers connected, owner-scoped periodic work and maps
  only retryable sync failures to WorkManager retry.
- A token-owned database run lease prevents separate foreground/background
  isolates from synchronizing the same owner concurrently and is reclaimable
  after expiry.
