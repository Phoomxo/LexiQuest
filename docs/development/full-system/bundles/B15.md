# B15 · Sync และ recovery

G7.1–G7.2 ตรวจรับ local แล้ว บน schema27 (50ตาราง)

- แก้ตัวล็อก sync ค้างเมื่อปล่อย SQLite gate ล้มเหลว; ยืนยัน offline → reopen → lost ack → retry โดยไม่เขียนซ้ำหรือทำ pending หาย
- นำเข้า `learning.sqlite` schema1 จาก support/documents แบบอ่านต้นฉบับอย่างเดียว เก็บครบ8ตารางเป็นประวัติเดิมในฐานหลัก พร้อม owner upgrade, export และ delete; ไม่สร้างคะแนน/รางวัล/SRS หรือส่ง outbox รุ่นเก่า
- ผ่าน **851 tests / 45ไฟล์**, Firestore emulator **176 tests**, CLI contracts **2ชุด**: [ผลตรวจ G7.2](../evidence/bundles/B15/G7.2-acceptance.json) · [ผล G7.1](../evidence/bundles/B15/G7.1-acceptance.json) · [ข้อบกพร่องและ retest](../evidence/bundles/B15/defects.json)

Auto-import รองรับ schema1 ที่มี owner เดียวและยังไม่มีฐานปลายทาง; ไฟล์หลายowner/ไม่รองรับ/ขัดกัน และปลายทางศูนย์ไบต์ ถูกเก็บและแจ้งข้อผิดพลาด ไม่เดาการรวมข้อมูล. ต้นฉบับ legacy เก็บไว้เพื่อย้อนกลับ แม้ลบรายการที่นำเข้าแล้วจากฐานปัจจุบัน; การลบนี้ไม่อ้างว่าลบไฟล์สำรองต้นฉบับด้วย

ทดสอบด้วยข้อมูลสังเคราะห์/SQLiteจริง/emulatorในเครื่อง. ไม่ได้ deploy, sync research จริง หรือทดสอบอุปกรณ์จริง/full release. Candidateกล้องยังปิดและbaselineเดิมไม่เปลี่ยน. G7 phase ยังมี G7.3–G7.7; ส่งต่อ B16 ตามลำดับที่อนุมัติ
