## Census and interpretation

[Semantic ledger](evidence/G0.3/semantic-ledger.json) inventories every changed
path in every unique non-merge commit, with full commit SHA, patch SHA-256,
endpoint Git blob/size, disposition and package owner. Main has 58 unique
commits: 48 non-merge plus 10 merge nodes. R15 has 382 unique commits, all
non-merge. The 10 merge nodes are separately enumerated; they are not 10 missing
features. [Census](evidence/G0.3/census.json) records path counts.

The unit is a commit/path delta, and a broad commit can have several owners.
The main commit decision is the semantic obligation; its per-path owner is a
consumer owner, not permission to drop the primary obligation. R15 is adopted
as a cumulative endpoint: `applicable` means keep that current implementation
under its owner's acceptance work, not replay every historical intermediate
patch. Removed/empty paths and old plan authority are `superseded`; identical
endpoint blobs are `equivalent`. No patch-title similarity is used as proof of
equivalence. The ledger includes docs, generated sources, tests, assets and
research paths so nothing vanishes from the census merely because it is not
production behavior. Historical reports remain historical observations.

`conflict` is a recorded incompatible contract, with the authority decision
below and a bounded owner obligation. It does not mean an unresolved Git merge.
All writer/schema/bootstrap **authority choices** are closed here. Required
implementation and runtime gates remain open in their designated packages.
G0.8 must adopt these obligations into the edition contract; it cannot declare
them runtime PASS from this source-inspection result.
