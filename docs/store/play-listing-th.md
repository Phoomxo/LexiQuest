# Google Play listing — ภาษาไทย

## ชื่อ

LexiQuest: ฝึกภาษาอังกฤษทุกวัน

## คำอธิบายสั้น

ฝึกคำศัพท์ อ่าน ฟัง พูด และทบทวนอย่างเป็นขั้นตอน พร้อมใช้งานออฟไลน์

## คำอธิบายเต็ม

LexiQuest ช่วยให้ผู้เรียนภาษาอังกฤษเก็บคำศัพท์ของตนเองและฝึกซ้ำผ่านแบบฝึกหลายรูปแบบ แอปจัดคำที่ควรทบทวน แสดงจุดที่ยังอ่อน และสรุปความก้าวหน้าโดยไม่บังคับให้เปิด Cloud

- เพิ่ม แก้ไข และนำเข้าคำศัพท์
- ฝึกด้วยแฟลชการ์ด แบบทดสอบ การอ่าน และการออกเสียง
- ดูคำที่ควรทบทวนและพัฒนาการเรียนรู้
- ใช้ธีมและรางวัลจากกิจกรรมในแอป
- ใช้ AI Tutor แบบ BYOK เมื่อผู้ใช้เปิดใช้งานเอง
- เรียนต่อแบบ local-first เมื่อบริการออนไลน์ไม่พร้อม

กล้อง ไมโครโฟน Cloud และ AI เป็นความสามารถเสริมที่เริ่มทำงานหลังผู้ใช้สั่งเท่านั้น การรู้จำเสียงอาจใช้บริการและเครือข่ายของผู้ให้บริการ Android แอปไม่ได้เปิดการเก็บข้อมูลงานวิจัยจริงในรุ่นทั่วไป

## ข้อความสำหรับผู้ทดสอบ

ใช้บัญชีทดสอบที่ผู้ดูแล Play Console จัดเตรียม ห้ามใช้ข้อมูลผู้เรียนจริงก่อน Privacy, Account Deletion และ Data Safety gates ผ่าน หลักฐานอุปกรณ์ต้องระบุ Version, Build ID และ artifact hash.
