# ประกาศความเป็นส่วนตัวและความยินยอม รุ่น 1

LexiQuest เป็นแอปทดลองเรียนคำศัพท์แบบ local-first การเข้าร่วมการเก็บข้อมูล
วิจัยเป็นความสมัครใจ ผู้ใช้ถอนความยินยอมได้จากหน้าตั้งค่าและยังเรียนออฟไลน์
ต่อได้ การถอนความยินยอมจะปิดการสร้างชุดข้อมูลวิจัยครั้งถัดไป แต่ไม่ลบ
ประวัติการเรียนที่แอปต้องใช้แสดงความก้าวหน้าโดยอัตโนมัติ

## ข้อมูลที่บันทึก

- หมวดและคำศัพท์ที่ผู้ใช้เพิ่ม แก้ไข ลบ หรือนำเข้า
- session การเรียน คำตอบ คะแนน เวลา และกำหนดทบทวน SRS
- ตำแหน่งการอ่าน ความสำเร็จ จุด รางวัล และ transaction ที่เกี่ยวข้อง
- สถานะซิงก์ ข้อผิดพลาดเชิงเทคนิค และข้อมูลประสิทธิภาพอุปกรณ์ที่จำเป็น
- เวอร์ชันความยินยอม เวลาให้ความยินยอม หรือเวลาถอน
- สถิติการใช้ AI แบบ local-only ได้แก่ provider, model, ผลสำเร็จ/หมวด error,
  latency และจำนวน token/cost เฉพาะที่ provider รายงาน โดยเก็บ raw event 90 วัน

ระบบไม่ใส่ API key รหัสผ่าน โทเคน prompt, response หรือ transcript ลงใน
ฐานข้อมูล usage, log หรือชุดข้อมูลวิจัย
เสียงดิบและภาพจากกล้องไม่ได้ถูกเก็บเป็นข้อมูลวิจัยโดยค่าเริ่มต้น

## การส่งข้อมูล

ข้อมูลหลักอยู่ใน SQLite บนอุปกรณ์ก่อน หากใช้บัญชีและ Cloud เปิดอยู่
ข้อมูลที่รองรับจะซิงก์กับ Firebase เพื่อสำรองและใช้งานต่อเนื่อง AI Tutor
ทำงานด้วย API key ของผู้ใช้เอง และส่งคำขอโดยตรงไปยัง provider ที่ผู้ใช้เลือก
ครั้งละหนึ่งราย ไม่มี fallback หรือ retry อัตโนมัติ สรุปการเรียนจะไม่ถูกส่ง
หากไม่ได้เปิดความยินยอมส่วนนั้น raw usage events จะไม่ซิงก์ขึ้น Cloud

## ทางเลือกและความเสี่ยง

ผู้ใช้สามารถไม่ยินยอม ถอนความยินยอม หยุดใช้กล้อง/ไมโครโฟน ไม่ตั้ง AI
provider หรือลบ usage ledger ในเครื่องได้ ความเสี่ยงที่เหลือรวมถึงค่า API
และอินเทอร์เน็ต
การสูญหายเมื่อถอนแอปหรือล้างข้อมูลก่อนซิงก์ และการประมวลผลโดยผู้ให้บริการ
เมื่อผู้ใช้เลือกใช้ Cloud หรือ AI provider ภายนอก

ก่อนแจก APK ผู้ดูแลต้องแนบช่องทางติดต่อ ระยะเวลาการเก็บข้อมูล
ผู้รับผิดชอบงานวิจัย และกระบวนการขอลบข้อมูลที่ใช้จริงในเอกสารส่วนตัว
ของโครงการ ห้ามแจกจ่ายหากข้อมูลเหล่านี้ยังไม่ถูกกำหนด
