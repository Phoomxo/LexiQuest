# LexiQuest รุ่นทดลอง 42 · อ่านคำแปลด้วย TalkBack

## สิ่งที่พบในรุ่น 41

บน Android 15 ผู้ทดสอบใช้ TalkBack ปัดไปที่ “ดูคำแปล” แล้วแตะสองครั้ง หน้าแสดงคำแปลถูกต้อง แต่โฟกัสย้ายไปที่ “กลับ” และค้างอยู่แม้รอให้หน้าจอนิ่ง ต้องปัดผ่านหัวข้อและตัวนับอีกสามครั้งจึงถึงคำแปล ทำซ้ำได้กับทั้ง `bus` และ `day` หลังเปิดรอบเดิมจากหน้าเรียน [ลำดับท่าทางและโฟกัสบน APK รุ่น 41](D:/LexiQuest-Storage/maintenance/2026-11-05/trial41/talkback-followup/gestures.jsonl)

## เกณฑ์ตรวจรับรุ่นทดลอง

- เมื่อแตะสองครั้งที่ “ดูคำแปล” โฟกัสต้องถึงบัตรที่มีทั้งคำศัพท์และคำแปลได้ทันทีที่พลิกเสร็จ ผู้เรียนจึงอ่านแล้วให้คะแนนต่อได้
- ตรวจกรณีแอนิเมชันปกติและลดการเคลื่อนไหว แยกผลจากการตรวจโฟกัสจริงของ Android บน APK ที่ลงนาม
- ตรวจฟีเจอร์ออฟไลน์ผ่านหน้าปกติของรุ่นที่ส่งมอบ ส่วนแบบประเมิน f28 ใช้ข้อมูลสังเคราะห์ในชุดทดสอบ Android แยกจาก APK สำหรับผู้ทดลอง
- เก็บการฝึก รางวัลและรายงานไว้ในเครื่อง การประเมินบน Vivo และความพึงพอใจต้องอาศัยผู้ทดลอง Cloud A/Billing การเปิดบริการภายนอกและการเก็บเงินจริงอยู่นอกขอบเขต
