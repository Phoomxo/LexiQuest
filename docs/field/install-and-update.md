# คู่มือติดตั้งและอัปเดต LexiQuest รุ่นทดลอง

เอกสารนี้ใช้กับ APK ที่ผู้ดูแลส่งให้โดยตรงเท่านั้น ตรวจชื่อไฟล์ เวอร์ชัน
และค่า SHA-256 กับใบแจ้งรุ่นก่อนติดตั้งทุกครั้ง หากค่าไม่ตรง ห้ามติดตั้ง
และให้ติดต่อผู้ดูแลการทดลองผ่านช่องทางที่แนบมากับชุดติดตั้ง

## ติดตั้งครั้งแรก

1. สำรองหรือส่งออกข้อมูลจาก LexiQuest รุ่นเก่าหากเคยติดตั้ง
2. ดาวน์โหลด APK ผ่านช่องทางส่วนตัวที่ผู้ดูแลกำหนด
3. ตรวจค่า SHA-256 ของไฟล์ให้ตรงกับ `release-manifest.json`
4. อนุญาตให้แอปจัดการไฟล์หรือเบราว์เซอร์ที่ใช้ดาวน์โหลดติดตั้งแอปจาก
   แหล่งนี้เฉพาะช่วงติดตั้ง
5. เปิด APK เลือกติดตั้ง แล้วปิดสิทธิ์ “ติดตั้งแอปที่ไม่รู้จัก” หลังเสร็จ
6. เปิด LexiQuest ตรวจเวอร์ชันและ Build ID ที่เมนูเกี่ยวกับแอป
7. อ่านประกาศความเป็นส่วนตัวและเลือกว่าจะเข้าร่วมการเก็บข้อมูลวิจัยหรือไม่

## อัปเดตโดยไม่ทำข้อมูลหาย

ห้ามถอนการติดตั้งหรือกดล้างข้อมูลก่อนอัปเดต ให้ติดตั้ง APK รุ่นใหม่ทับรุ่นเดิม
ซึ่งต้องใช้ลายเซ็นดิจิทัลเดียวกัน หลังเปิดแอปให้ตรวจว่าหมวดคำศัพท์ ประวัติ
SRS คะแนน และสถานะการอ่านยังอยู่ หาก Android แจ้งว่าลายเซ็นไม่ตรง
ให้หยุดและติดต่อผู้ดูแล ห้ามแก้ด้วยการถอนการติดตั้ง

## กู้คืนเมื่อมีปัญหา

- หากแอปเปิดไม่ได้ ให้บันทึกข้อความผิดพลาด รุ่นมือถือ รุ่น Android และ Build ID
  แล้วส่งผ่านช่องทางสนับสนุน
- หากซิงก์ไม่ได้ ยังสามารถเรียนออฟไลน์ต่อได้ อย่าล้างข้อมูลแอป
- หากกล้อง เสียง หรือ AI ใช้ไม่ได้ ให้ใช้ส่วนคำศัพท์ Quiz SRS และ Reading
  ต่อได้ตามปกติ
- อย่าส่ง API key รหัสผ่าน ไฟล์ฐานข้อมูล หรือข้อมูลส่วนบุคคลในช่องทาง feedback
