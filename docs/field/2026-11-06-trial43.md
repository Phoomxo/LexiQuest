# LexiQuest รุ่นทดลอง 43 · ผลตรวจรับก่อนทดลองออฟไลน์

รอบนี้แก้ 9 ประเด็นจาก [critique รุ่น 42](../../.impeccable/critique/2026-11-05T17-29-24Z__lib.md) และ [รายงานก่อนหน้า](../../.impeccable/critique/2026-11-05T14-44-22Z__lib.md) ใช้บัญชีผู้เรียนสังเคราะห์และแพ็กเริ่มต้นในเครื่อง ขอบเขตคือการฝึกออฟไลน์ Cloud A/Billing การเก็บเงินจริง และการรับผู้เข้าร่วม Research อยู่นอกการตรวจรอบนี้

## เกณฑ์ตรวจรับ

| เส้นทาง | สิ่งที่ผู้ทดลองควรเห็น |
| --- | --- |
| นิยามและคำใบ้ | อ่านเบาะแสของ `cat` ได้ก่อนตอบ ประโยคตัวอย่างเต็มแสดงหลังตอบหรือขอเฉลย นิยามที่เขียนคำตอบไว้เองยังใช้ฝึกได้ |
| ควิซและเติมคำ | หลังบันทึก เห็นผลกับปุ่มไปต่อในจอเดียว เข้าถึงรายละเอียดภายหลัง และผู้เรียนเป็นคนกดไปต่อเอง |
| รายงานเนื้อหา | ก่อนยืนยันรู้ว่ารายงานจะเก็บที่เครื่อง ผู้จัดยังไม่ได้รับ เปิดดูคำที่รายงานได้ทันทีและพบรายการเดียวกันในกล่องรายงานเนื้อหา ตัวเลขรายงานคำศัพท์ระบุประเภทชัดเจน |
| ตั้งเตือน | ค้นหา “กรุงเทพ” หรือ “Bangkok” แล้วเลือก `Asia/Bangkok` เมื่อบันทึกและกลับมาเปิดใหม่ เวลาและเขตเวลาตรงกับที่เลือก |
| ฝึกจากหน้าเรียนและจากผลข้อผิด | การเลือกคำอ้างอิงเปิด “ฝึกความหมาย” การฝึกซ้ำจากข้อผิดเปิด “ฝึกคำที่ผิด” และใช้คำเดิม |
| จับคู่ | เมื่อจับคู่ผิด ข้อความระบุทั้งคำและความหมายที่เพิ่งเลือก TalkBack อ่านข้อความเดียวกันได้ ผู้เรียนแก้คู่เองและผลรวมยังนับครั้งที่ตอบผิด |
| ร้านรางวัล | แสดงเหรียญที่ใช้ได้ การซื้อหักตามราคา การสวมของที่ซื้อแล้วรักษายอดเดิม |
| ความสำเร็จ | ระบุว่า XP มาจากการเรียนและภารกิจ แสดงจำนวนคำตอบแยกจากยอด XP |
| จับเวลาโฟกัส | ระหว่างจับเวลาหรือพักให้แสดงเวลาที่เหลือ หลังจบให้แสดงเวลาโฟกัสจริง ทั้งกรณีจบก่อนเวลา จบจากพัก และครบเวลา |

ตรวจตามลำดับจากเทสต์รายหน้าที่จำลองอาการ ตรวจโค้ดและชุดทดสอบรวม แล้วติดตั้ง APK ที่ลงนามบน Android emulator ผ่านเมนูปกติ เก็บหลักฐานการอัปเกรดและการใช้ฟีเจอร์แยกจากหลักฐานบนโทรศัพท์จริง
