# ระเบียบปฏิบัติการทดลองภาคสนาม LexiQuest รุ่น 1

เอกสารนี้เป็นระเบียบปฏิบัติทางเทคนิคสำหรับการทดลอง 30 คน ไม่ใช่การรับรอง
จากคณะกรรมการจริยธรรม ผู้รับผิดชอบโครงการต้องตรวจข้อกำหนดของสถาบัน
และอนุมัติเอกสารนี้ก่อนเชิญผู้เข้าร่วม

## วัตถุประสงค์และขอบเขต

ประเมินความเสถียร การใช้งานออฟไลน์ การซิงก์ ประสิทธิภาพบนอุปกรณ์หลายระดับ
และผลการเรียนที่คำนวณจากคำตอบจริง ผู้เข้าร่วมใช้รหัสนามแฝงแทนชื่อ
และไม่ต้องส่งรหัสผ่าน API key ภาพจากกล้อง หรือเสียงดิบให้โครงการ

## ข้อมูลและการลดความเสี่ยง

- เก็บเฉพาะกิจกรรมการเรียน คำตอบ คะแนน เวลา SRS สถานะการอ่าน
  ความสำเร็จ ธุรกรรมรางวัล และข้อมูลประสิทธิภาพอุปกรณ์ที่จำเป็น
- ชุดข้อมูลวิจัยไม่รวมอีเมล รหัสผ่าน token, Gemini key, prompt ที่ไม่ปกปิด
  ภาพกล้อง หรือเสียงดิบ
- ข้อมูลอยู่ในเครื่องก่อนและซิงก์เฉพาะเมื่อบัญชี Cloud และนโยบาย Cloud
  เปิดใช้งาน
- การถอนความยินยอมหยุดการส่งออกชุดข้อมูลวิจัย แต่ไม่ทำลายการเรียน
  ออฟไลน์หรือไฟล์ส่งออกส่วนตัว

## ระยะเวลา

รอบทดลองใช้งานกำหนด 30 วันนับจากวันที่ผู้เข้าร่วมติดตั้ง APK ที่อนุมัติ
ข้อมูลสนับสนุนที่มีรหัสนามแฝงและชุดข้อมูลดิบให้เก็บไม่เกิน 180 วัน
หลังปิดรอบทดลอง แล้วลบสำเนาที่ไม่จำเป็น ผลรวมที่ไม่สามารถย้อนกลับ
ไปหาผู้เข้าร่วมอาจเก็บเพื่อรายงานผลตามข้อกำหนดของสถาบัน

## เหตุการณ์และการหยุดระบบ

เมื่อพบข้อมูลข้ามบัญชี secret รั่ว ข้อมูลสูญหายเป็นวงกว้าง crash/ANR
ที่ปิดกั้นการเรียน หรือค่าใช้จ่ายผิดปกติ ผู้ดูแลต้องหยุดการแจก APK
ปิด Cloud ด้วย kill switch โดยไม่ลบ Drift/outbox แจ้งผู้เข้าร่วม
และสร้าง release candidate ใหม่ ผลทดสอบของ APK hash เดิมใช้กับ APK ใหม่ไม่ได้

## การอนุมัติก่อนแจก

ผู้ดูแลต้องบันทึกผู้อนุมัติ วันที่ ช่องทาง support ส่วนตัว ระยะเวลาตอบกลับ
วิธีขอลบข้อมูล และ SHA-256 ของ APK ใน evidence ที่ไม่ commit เข้า repository
Final gate จะไม่ผ่านหากยังไม่มีหลักฐานเหล่านี้หรือมือถือจริงครบสามระดับ
