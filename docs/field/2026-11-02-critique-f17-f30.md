## f17 Immediate Answer Feedback

- Source: `lib/screens/quiz_screen.dart:287`, `:829`, `:838`, `:1048`, `:1209`.
  Selecting an answer enters the pending/save path. Only an
  `AnsweredQuizQuestion` renders correct/incorrect feedback. Optional haptics are
  outside persistence success and cannot convert a committed answer into retry.
- Workflow: answer → acknowledged feedback → next question → completed session.
  Pending state has a progress label and explicit original-answer retry. A failed
  load has a separate reload path. Retained owner/disposal callbacks are guarded.
- Critique: the live region and explicit pending state meet the task better than
  optimistic success. The wrong-answer translation wording is too narrow for a
  shared lesson shell. Long lexical feedback and audio controls need rendered
  hierarchy/scroll review; source inspection cannot prove their readability.
- Acceptance: preserve existing tests in `test/screens/quiz_screen_test.dart`
  for durable answer before score, owner change, delayed acknowledgement and slow
  haptics. Check Definition and meaning feedback at 320dp/200% text with the next
  action reachable. Do not advance or show success on an unacknowledged write.

## f18 Contrastive Distractor Explanation

  `lib/screens/quiz_screen.dart:862`. The domain getter requires an acknowledged,

- Acceptance: retain wrong-option/source-pin and acknowledgement tests in the
