# LexiQuest รุ่นทดลอง 41 · เมื่อบัตรคำอ่านออกเสียงไม่ได้

ทำต่อจาก [ผลรุ่น 40](2026-11-05-trial40.md) ที่คอมมิต `b2aa46eb` ในสาขา `codex/remaining-system-readiness` ใช้โปรไฟล์ `offlineTrial` สำหรับ Android

## เกณฑ์ตรวจรับ

- เมื่อระบบเสียงปฏิเสธการอ่าน ผู้เรียนต้องเห็นข้อผิดพลาดที่ TalkBack รับรู้ได้ ปุ่มฟังพร้อมให้ลองใหม่ ปุ่มหยุดกลับเป็นปิด และยังพลิกบัตรหรือให้คะแนนได้
- การฟังที่ล้มเหลวต้องคืนโอกาสนับเวลาฝึกตามการโต้ตอบครั้งถัดไปของผู้ที่เปิดการนับเวลา การตอบกลับของงานเสียงเก่าต้องไม่เปลี่ยนสถานะของบัตรหรือเสียงรายการใหม่
- คำแนะนำต้องตรงกับจำนวนคำและชื่อปุ่มจบบนหน้าจอ บอกวิธีลองฟังคำเดิมซ้ำ แยกผล TalkBack ออกจากความพึงพอใจ และให้ผู้ทดลองเลือกข้ามคำถามได้
- ตรวจไฟล์แจกที่ลงนามจากเส้นทางบัตรคำจริง แยกสิ่งที่ระบบเสียงตอบรับออกจากสิ่งที่คนได้ยิน เก็บผลไว้ในเครื่อง Cloud A/Billing การเก็บเงินจริง การเปิดผู้ให้บริการภายนอกและการรับสมัครวิจัยอยู่นอกขอบเขต
