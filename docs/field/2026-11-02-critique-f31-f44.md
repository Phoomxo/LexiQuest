## f31 Achievement and milestone

The learner opens Achievements from progress, reads actual unlock facts and may
preview an eligible share card. `lib/screens/achievements_screen.dart:32` binds
progress to owner/lifecycle state. Its preview at110 checks source evidence before
opening a composer and revalidates again before output. Loading and error states
have semantic announcements; retry refreshes the binding. Empty accounts do not
receive sample badges. Unknown achievement identifiers stay internal.

Disposition: no proven new defect. The distinction between evidence-backed unlocks
and decorative rewards is useful and must survive future copy changes. Read
`test/screens/achievements_screen_test.dart:9` through the retry case at68 and
`test/features/motivation/achievement_source_boundary_test.dart`. Acceptance is
loading, empty, unavailable/retry, actual unlock date and owner-switch behavior,
then f34 preview with the same stored source. Physical screen-reader order remains
unverified here.

## f35 Learning preference and goal quiz

The optional onboarding uses the same editor and owner-scoped profile as later
settings. `lib/features/learning_profile/presentation/learning_profile_editor_screen.dart:169`
prepares one immutable command, validates fields, saves and reports success only
after acknowledgement. Skip prepares an explicit skipped state. Empty reads do not
create a profile or enable reminders/research.

Finding shared with f36: `_edited` at159 tracks a dirty draft, but the reviewed
build method from263 has no `PopScope` or equivalent leave interception. Back can
dispose the editor and discard entered goal/date/minutes without a choice. This is
a source-confirmed missing guard, not yet a runtime-reproduced finding in this
worker. Root owns the reproduction and any fix; do not create a duplicate task.
Acceptance should cover clean Back, dirty Back with stay/discard, saved onboarding
completion and Back while a save is uncertain. Never disable owner invalidation.

Existing `test/screens/learning_profile_editor_screen_test.dart:379` covers optional
skip; its invalid-date, late-load and immutable retry cases protect adjacent flows.

Acceptance also includes exported/purged profile data and no extra research rows.

## f40 Local-first operation

`lib/features/sync/application/sync_engine.dart:74` skips unauthenticated owners or
disabled policy before claiming outbound work. Per-owner mutex and durable run
lease bound concurrent sync. The loop preserves failure/conflict evidence and
continuation budgets instead of spinning indefinitely. Local records remain the

Disposition: no proven new defect in this slice. Cloud exclusion must not be
implemented by removing local persistence or weakening export/deletion fences.
`test/features/sync/sync_engine_test.dart:81`,168,218,244 and537 explicitly cover
kill switch, stationary cursor, older checkpoint, guest skip and isolate overlap.

account switch isolation. Live cross-device convergence is not claimed or pursued
under the excluded Cloud workstream.
