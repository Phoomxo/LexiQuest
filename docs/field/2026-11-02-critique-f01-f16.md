## Workflow ที่เชื่อมฟีเจอร์

1. Catalog → preview/detail → install → lexical binding → setup → Quiz/SRS.
   จุดสำคัญคือ re-read owner/version หลังทุก asynchronous UI boundary ไม่ใช่แค่
   disable ปุ่ม การอ่าน source รอบนี้พบ guard ที่ catalog:697–759 และไม่มี
   เหตุผลให้แทนด้วย global busy flag ตัวเดียว
2. Hub → recommendation → practice → acknowledged answer → result → History.
   Keep recognition, assisted input และ independent recall แยกกันตาม accepted
   contracts ผลลัพธ์หรือการกดต่อไม่ใช่หลักฐานว่า writer สำเร็จก่อน ACK
3. Typing/scratchpad → explicit draft save → answer stage/commit → finish.
   Ink ไม่ใช่คำตอบ ร่างไม่ใช่ event และการปิดหน้าไม่เท่ากับส่งคำตอบ
   ให้ตรวจคนใช้งานจริงด้านความเข้าใจ โดยไม่เปลี่ยน persistence semantics เงียบ ๆ
4. Every path → background/owner change/error → retry/resume.
   Preserve original intent and session identity. Exact SRS deck restoration
   after process restart is not certified by this review; ordinary persisted
   ratings and configured/native checkpoint resume are separate behaviors.
