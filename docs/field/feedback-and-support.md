# แนวทาง Feedback และ Support สำหรับผู้ดูแล

ก่อนแจก APK ผู้ดูแลต้องสร้างช่องทาง feedback และ support ที่เข้าถึงได้จริง
จากต่างจังหวัด แล้วบันทึกชื่ออ้างอิงช่องทางไว้ใน evidence ส่วนตัว
ห้ามใส่อีเมลส่วนตัว โทเคน webhook หรือข้อมูลผู้เข้าร่วมใน repository

แบบรายงานควรถามเฉพาะ:

- รหัสผู้เข้าร่วมแบบนามแฝง
- รุ่นมือถือและ Android
- Version และ Build ID
- วันที่ เวลา เครือข่าย และขั้นตอนก่อนพบปัญหา
- ผลที่คาดหวังและผลที่เกิดขึ้น
- ภาพหน้าจอที่ตรวจแล้วว่าไม่มี API key รหัสผ่าน หรือข้อมูลส่วนบุคคล

กำหนด SLA การตอบกลับ ผู้รับผิดชอบ แผนปิด Cloud และวิธีแจ้ง known limitation
ในเอกสารส่วนตัวของโครงการ Final gate จะไม่ผ่านหาก evidence ยังใช้ข้อความ
