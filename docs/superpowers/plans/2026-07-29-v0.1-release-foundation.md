# LexiQuest v0.1 Release Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a clean, testable Android v0.1 foundation that builds without Supabase, reports truthful runtime health, uses one Material 3 theme, and carries version `0.1.0+1`.

**Architecture:** This is Plan 1 of the approved complete-system program. It removes the unused second cloud runtime before feature work, keeps Firebase as the identity/sync boundary, and makes the Flutter shell depend only on typed application status. Product artwork accepts verified HTTPS URLs or a truthful built-in default presentation without constructing Supabase URLs.

**Tech Stack:** Flutter 3.44.7, Dart 3.12.2, Material 3, Firebase Core/Auth/Firestore/App Check, Drift/SQLite, PowerShell verification, GitHub Actions, Android API 36 with Android 10 as the supported device floor.

## Global Constraints

- The primary architecture is on-device first.
- The supported baseline is Android 10 or newer, 4 GB RAM, and 2 GB available storage; 6 GB RAM is recommended.
- The Android package version is `0.1.0+1`.
- Firebase is the only account and synchronization platform in v0.1.
- Gemini is the only AI provider and uses a user-supplied key; no provider key is bundled.
- Supabase is absent from the v0.1 runtime and Android build inputs.
- Production code must not return mock, sample, simulated, or fabricated results.
- Core learning must open, run, and save without cloud availability.
- Existing user changes outside this isolated worktree must not be modified.
- Every production behavior change follows red-green-refactor TDD.
- Branch names for this program must not contain `codex`.

## Program decomposition

The approved system is split into independently reviewable plans so each
subsystem ends in working software:

1. **Release foundation** — this plan.
2. **Typed navigation and accounts** — canonical routes, registration,
   verification, guest upgrade, forgot/reset/change password.
3. **Offline data and synchronization** — Drift source of truth, migrations,
   outbox, conflicts, reconnect, and cross-device restore.
4. **Core learning completion** — vocabulary, CEFR, reading, SRS, quizzes,
   practice modes, weakness analysis, and persisted recommendations.
5. **Trusted game and economy** — world, bosses, ghost duel, points, quests,
   achievements, shop, equipment, wallpapers, and trusted writers.
6. **On-device media** — capability tiers, model packs, camera recognition,
   speech, pronunciation, native TTS, audio lifecycle, and OmniVoice fallback.
7. **Gemini BYOK** — encrypted key lifecycle, Gemini adapter, AI tutor,
   generated content, quotas, and offline truthfulness.
8. **Exports and release qualification** — analytics, research exports,
   device matrix, 30-person acceptance, signed APK, rollback, and evidence.

Each subsequent plan consumes the committed interfaces and green baseline
created by its predecessor.

- [ ] **Step 3: Implement the resolver**

```dart
sealed class ProductArtwork {
  const ProductArtwork();

  String? get storageValue;
}

final class DefaultProductArtwork extends ProductArtwork {
  const DefaultProductArtwork();

  @override
  String? get storageValue => null;

  @override
  bool operator ==(Object other) => other is DefaultProductArtwork;

  @override
  int get hashCode => runtimeType.hashCode;
}

final class NetworkProductArtwork extends ProductArtwork {
  const NetworkProductArtwork(this.uri);

  final Uri uri;

  @override
  String get storageValue => uri.toString();

  @override
  bool operator ==(Object other) =>
      other is NetworkProductArtwork && other.uri == uri;

  @override
  int get hashCode => uri.hashCode;
}

ProductArtwork resolveProductArtwork(Map<String, Object?> product) {
  final rawUrl = product['image_url'];
  if (rawUrl is! String) return const DefaultProductArtwork();
  final uri = Uri.tryParse(rawUrl.trim());
  if (uri == null ||
      uri.scheme != 'https' ||
      !uri.hasAuthority ||
      uri.userInfo.isNotEmpty) {
    return const DefaultProductArtwork();
  }
  return NetworkProductArtwork(uri);
}
```
