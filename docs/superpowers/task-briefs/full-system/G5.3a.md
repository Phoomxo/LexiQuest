ตรวจ tools/train_camera_pilot.py, tools/export_camera_pilot.py, tools/camera_accuracy.py, existing model/label manifest และ compute จริงก่อนเลือก fine-tune. กำหนดประเภทสิ่งของเชื่อมคำศัพท์ ไม่อนุมาน SKU/แบรนด์. สำรวจ 7-Eleven, Big C, Lotus’s, Makro และแหล่งอาหาร/วัตถุดิบ/ของใช้/เครื่องมือ/วัสดุก่อสร้างอื่นจากเว็บจริง; บันทึก access/usage evidence และ alternatives. ภาพสาธารณะไม่ใช่สิทธิ์ฝึกอัตโนมัติ; ไม่ bypass access. ไม่รอผู้ใช้ถ่ายภาพกล้องเพื่อเริ่ม train.

**Acceptance:** มี taxonomy/label-to-vocabulary contract, source inventory พร้อมหลักฐานสิทธิ์/การเข้าถึงจริงและทางเลือกที่ใช้ได้, toolchain/compute inventory กับวิธีฝึกที่ทำได้; ไม่ claim collection/training ก่อนมี artifacts.

**Requirements:** COV-f13, COV-f41, A-MODEL, FORM-09, G5. อ่าน Master/ledger/workflow/accepted handoff และ relevant callers/tools ก่อน implementation. ออก detailed implementation plan ตาม actual toolchain; owner paths เริ่มต้นอยู่ในledgerและขยายที่จำเป็นได้.

ใช้ภาพอินเทอร์เน็ตสำหรับ train/development validation ตอนนี้ ไม่รอภาพจากผู้ใช้. เก็บภาพกล้องจริงตอน device testing ภายหลัง; ผลกล้องจริง pending จนทดสอบจริง ห้ามใช้คะแนนเว็บอ้างแทน. Fresh test ห้ามปรับ threshold/เทรน; หากนำภาพกล้องที่ดูแล้วมาแก้/ฝึกให้จัดเป็น development และใช้ชุดกล้อง held-out ใหม่ตรวจรับ. เก็บ unknown-object evaluation แยกชัดเจน.
