## สิ่งที่ตรวจพบในระบบเดิม

- `WordScrambleScreen`: เลือก/ลากตัวอักษร ตรวจคำตอบ และบันทึกผลผ่านระบบเดิม แต่ยังไม่มีคำใบ้ความหมายและแผงตามภาพ
- `FillInTheBlanksScreen` / `ClozeModeAdapter`: ประโยคที่ผ่านการตรวจและผูกกับรุ่นเนื้อหา มีคำตอบแบบเลือกหรือพิมพ์ พร้อมแยกผลตามการใช้ตัวช่วย
- `SentenceScrambleScreen`: มีโหมดเรียงคำเป็นประโยคแยกอยู่แล้ว
- `SpeakToTextScreen`: มีบริการอ่านตัวอย่างและรับเสียงพูด รวมการควบคุมเมื่อออกจากหน้า
- หลักฐานการพูดใช้ `transcript-edit-distance-v1`: ความเหมือนของข้อความที่ระบบรู้จำ ไม่ใช่การวิเคราะห์หน่วยเสียง จังหวะ หรือสำเนียงโดยตรง

## ทางเลือก

1. **แนะนำ: เชื่อมเป็นกิจกรรมต่อเนื่องในหน้าเรียนเดียว** เติมคำให้สมบูรณ์ ตรวจคำตอบ แล้วฟัง/ฝึกพูดประโยคนั้น ใช้หน้าการ์ดคำตามภาพและปุ่มหลักตามขั้นตอน ผู้เรียนไม่ต้องออกไปเลือกโหมดเสียงเอง แต่ต้องจัดการสถานะเสียงและการบันทึกให้ไม่ซ้ำ
2. **เชื่อมด้วยปุ่มไปยังโหมดเดิม** ทำได้โดยเปลี่ยนหน้าจอน้อยกว่า แต่ผู้เรียนต้องย้ายหน้าและต้องรักษาบริบทคำ/ประโยคข้ามหน้า
3. **ฝึกพูดเป็นเงื่อนไขผ่านทุกข้อ** รวมประสบการณ์เข้มข้นขึ้น แต่ไม่เหมาะเป็นค่าเริ่มต้นเมื่อผู้เรียนอยู่ในที่พูดไม่ได้หรือระบบรู้จำเสียงไม่พร้อม

## แบบที่เสนอ

แสดงโจทย์ทีละข้อ มีหัวข้อภาษาไทย แถบความคืบหน้า และประโยคขนาดอ่านง่าย เช่น `I look in the ____.` พร้อมชุดคำ `mirror / window / bottle` ตัวอย่างนี้เป็นเพียงการอธิบายแบบ ไม่ใช่เนื้อหาที่เพิ่มเข้าฐานข้อมูลแล้ว

1. ผู้เรียนเลือกคำเติมช่องว่าง; โจทย์ฝึกสะกดใช้ตัวอักษรเรียงคำ ส่วนโจทย์เรียงประโยคใช้ชุดคำ ทั้งสามแบบใช้รูปแบบหน้าจอสอดคล้องกัน แต่ไม่บังคับทุกคำผ่านทั้งสามเกม
2. กด **ตรวจคำตอบ** แล้วเห็นคำตอบและคำอธิบายจากเนื้อหาที่มีจริง ปุ่มหลักเปลี่ยนตามสถานะ ไม่แสดงทุกตัวเลือกพร้อมกัน
3. หลังตอบถูกหรือเปิดเฉลยแล้ว กด **ฟังประโยค / หยุดเสียง** เพื่อฟังประโยคสมบูรณ์ การฟังก่อนตอบต้องผ่านกติกาตัวช่วยเดิมและไม่บันทึกเป็นการจำได้เอง
4. ข้อเสนอเริ่มต้นคือ **ฝึกพูด / หยุด / ลองอีกครั้ง / ข้ามการพูด** ใช้ทั้งการฟังตัวอย่างและไมโครโฟน โดยผู้ใช้ยังเลือกได้ว่าจะเอาทั้งสองอย่างหรือเฉพาะอย่างใดอย่างหนึ่ง
5. แสดงข้อความ **ระบบได้ยินว่า…** กับผลเทียบประโยคอย่างตรงไปตรงมา กรณีเงียบ ถูกปฏิเสธสิทธิ์ หรือบริการไม่พร้อม ให้ลองใหม่หรือเรียนต่อได้ ไม่มีคะแนนเสียงที่แต่งขึ้น
6. กด **ข้อต่อไป** แล้วเชื่อมกับประวัติและการทบทวนเดิม แยกหลักฐานการเลือกคำ การใช้คำใบ้ และการฝึกพูด ไม่เพิ่ม XP หรือปรับ SRS ซ้ำเพียงเพราะฟัง/พูดประโยคเดิมอีกครั้ง

มือถือใช้การ์ดเรียงแนวตั้ง ชุดคำอยู่ใกล้ช่องตอบ ปุ่มหลักอยู่ในตำแหน่งกดถึง และตัวช่วยเปิดเพิ่มเมื่อจำเป็น แผงข้างในภาพปรับเป็นส่วนย่อได้บนจอแคบ ใช้สีและองค์ประกอบของ LexiQuest

หัวใจและตัวช่วยในภาพยังไม่มีข้อกำหนดเรื่องจำนวน การลด การเติม หรือค่าใช้จ่ายที่ยืนยันไว้ ข้อเสนอนี้จึงยังไม่เพิ่มระบบชีวิต/เงินอีกชุด และไม่ให้ปัญหาไมโครโฟนลดหัวใจ

## ขอบเขตการเชื่อมระบบ

- ใช้แค็ตตาล็อก 8/44 และบริการบทเรียน/เสียง/เจ้าของข้อมูลเดิม ไม่เพิ่มโหมด serialized หรือ schema เพียงเพื่อเปลี่ยนประสบการณ์หน้าจอ
- ใช้ประโยคที่ผ่านการตรวจและรุ่นเนื้อหาตรงกับ session; ถ้าไม่มีประโยคที่ใช้ได้ ให้บอกเหตุผลและกลับไปฝึกคำได้ ไม่แต่งโจทย์หรือเฉลยสดแล้วอ้างว่าตรวจแล้ว
- หยุดเสียง/ไมโครโฟนเมื่อเปลี่ยนข้อ ย้อนกลับ แอปพัก หรือเจ้าของข้อมูลเปลี่ยน; ผลลัพธ์ล่าช้าจากข้อเก่าต้องไม่เขียนลงข้อใหม่
- การกดซ้ำและ retry ต้องอ่าน/บันทึกผ่าน authority เดิม โดยผลการเรียนหนึ่งรายการไม่กลายเป็นหลายรายการ ไม่มีการเปิดวิจัยหรือส่งข้อมูลจริงเพิ่มอัตโนมัติ
- การเชื่อมหลักฐานเสียงเข้ากับ session ที่ยังเปิด/ปิดแล้วต้องตรวจสัญญาของ controller เดิมในแผน implementation ก่อนลงมือ ไม่ให้ presentation สร้าง session หรือ reward authority ซ้ำ

## เกณฑ์ตรวจรับที่เสนอ

- กดเลือก/ย้าย/แก้คำตอบ ตรวจข้อถูก/ผิด ดูคำอธิบาย และไปข้อต่อไปได้จริง; ตัวอักษร/คำซ้ำต้องแยกตำแหน่งถูกต้อง
- ฟัง หยุด พูด ลองใหม่ และข้ามทำงานตามสถานะ; ทดสอบสิทธิ์ถูกปฏิเสธ เสียงเงียบ provider failure และผลลัพธ์มาช้า
- กดซ้ำ ย้อนกลับ ปิด/เปิดใหม่ และ retry ไม่ทำหลักฐาน/รางวัลซ้ำ ไม่ข้ามเจ้าของข้อมูล และไม่อ้างบันทึกสำเร็จก่อนยืนยัน
- หน้าจอแคบ ตัวอักษร 200% แป้นพิมพ์และ semantic actions ใช้งานได้ รวมตรวจจริงบน vivo แยกจาก host tests
- รัน subsystem tests และ regression หลังเชื่อมกิจกรรมเสร็จ; สถานะผ่านของ UI รุ่นก่อนหน้าไม่ใช้แทนผลทดสอบฟังก์ชันใหม่นี้
