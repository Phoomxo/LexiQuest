## การจัดแนวการ์ดตามข้อเสนอแนะล่าสุด

ผู้ใช้ระบุว่ารูปในกริดการ์ดควรอยู่กึ่งกลาง ประเมินแล้วใช้กติกาแยกตามหน้าที่: การ์ดหมวดและวิธีฝึกในกริดให้รูป ชื่อสั้น และข้อมูลประกอบสั้นอยู่กลาง โดยรักษาขนาดรูปและระยะบน/ล่างเท่ากัน; หัวข้อส่วน ข้อความยาว ตัวอย่างประโยค และแถวแนวนอนยังชิดซ้าย ไม่ใช้การชิดซ้ายเป็นค่าเดียวสำหรับทุกองค์ประกอบ และไม่ย้ายรูปไปชิดขวาโดยไม่มีหน้าที่รองรับ

### แบบสังเคราะห์หลังตรวจภาพจริง

สร้างหนึ่งแบบต่อยอดจากการเปรียบเทียบเดิม: คลังชุดคำ → เลือกวิธีฝึก → ทบทวนคำพร้อมตัวอย่าง → แบบทดสอบพร้อมผลตอบกลับ แนบภาพ 2473, 2550, 2551, 2555 และภาพ Duolingo เข้า built-in ImageGen โดยตรง สร้างภาพต้นฉบับใหม่ ไม่ใช้ภาพหน้าจอภายนอกเป็น asset ในแอป

ภาพร่าง: `C:/Users/Phet/.codex/generated_images/01a0934a-7d56-7160-9f7d-edaafcccaf11/exec-ff34f466-778a-405b-812e-e9522cf16281.png`

ข้อสรุปจากภาพ: โครงเลือกชุดแล้วเลือกวิธีฝึกสัมพันธ์กับข้อมูลคำศัพท์ได้ชัดกว่า A–C ที่เน้นหน้าศูนย์รวมทั่วไป การแยกส่วนคำ ตัวอย่าง และปุ่มตอบช่วยลดข้อมูลต่อกันโดยไม่มีลำดับ นี่เป็นข้อเสนอจากการตรวจภาพ ยังไม่ใช่ผล usability test

ข้อแก้ก่อนนำไปใช้: หน้าแรกมีชื่อ LexiQuest ซ้ำเหนือชื่อหน้าและแถบล่างทับการ์ดท้ายกริด ต้องตัดหัวซ้ำและให้เนื้อหาเลื่อนพ้นแถบล่าง; ภาพตกแต่งชุดคำต้องไม่กินพื้นที่จนกิจกรรมหาย; อย่าแสดงร้อยละว่าเป็นความชำนาญเมื่อข้อมูลเป็นเพียงจำนวนคำที่ฝึก; ตรวจป้ายแถบล่างที่ 200%; หน้าทบทวนในภาพเป็นสถานะเปิดคำตอบแล้ว ตัวเลข 20 คำและชื่อชุดทั้งหมดเป็นข้อมูลสาธิต ไม่ใช่การตกลงแบ่งเนื้อหาใหม่หรือผลผู้เรียนจริง

การค้นครั้งนี้หยุดคำสั่ง Python ที่ค้น regex ในประวัติด้วยรูปแบบไม่เหมาะสมแล้ว เปลี่ยนเป็นการค้นพาธเฉพาะด้วย rg จนพบไฟล์ ไม่มีการลบภาพ ไม่มีการแก้ Flutter/ติดตั้ง APK และไม่มีโปรเซสค้นหาค้างอยู่จากคำสั่งนั้น

วันที่ 2026-09-12 · สถานะ: แบบร่างภาพสำหรับพิจารณา ยังไม่ใช่หน้าจอที่ติดตั้งแล้ว

## ข้อกำหนดจากผู้ใช้

ใช้ ALLTCAS และ Duolingo เป็นแหล่งอ้างอิงการจัดวาง ทำหน้าเรียน คำศัพท์ รางวัล และเมนูให้มีโครงสร้างร่วมกัน ใช้คำทั่วไปที่ผู้เรียนเข้าใจทันที โดยเฉพาะไม่ใช้ SRS เป็นชื่อเมนู ไม่แก้ปัญหาด้วยการเพิ่มหัวข้อและย่อหน้าต่อกันเท่านั้น

คำสั่งล่าสุดเรื่องภาษาแทนที่รายการคำแสดงผลที่ขัดกันใน `2026-09-01-thai-navigation-glossary-design.md` เช่น “ทบทวนแบบเว้นระยะ (SRS)” โดยคงเอกสารเดิมเป็นหลักฐานย้อนหลัง ไม่เปลี่ยนชื่อ route, feature ID, ฐานข้อมูล หรือความหมายของผลการเรียน

## แนวทางที่เสนอ

เลือกหน้าศูนย์รวมการฝึกที่มีปุ่มหลักหนึ่งจุดและกิจกรรมจัดเป็นกลุ่ม เพราะเข้ากับความสามารถปัจจุบันและผู้เรียนเลือกสิ่งที่จะฝึกได้เร็ว แนวทางเส้นทางบทเรียนต่อเนื่องต้องมีลำดับหลักสูตรรองรับก่อน ส่วนรายการกิจกรรมยาวทั้งหมดในหน้าเดียวทำให้ผู้เริ่มต้นเลือกยาก

แบบร่างแสดงหนึ่งระบบผ่านสี่หน้า: เรียน, คำศัพท์, รางวัล, เมนู ภาพนี้แสดงทิศทางและตัวอย่างเนื้อหา ไม่ใช่รายการฟีเจอร์ทั้งหมด ห้ามตัดกิจกรรมอื่นทิ้งเพียงเพราะไม่ได้ปรากฏในภาพ

## โครงสร้างร่วม

1. หน้าหลักใช้หัวหน้าสั้น ชิดซ้าย ตำแหน่งและความสูงเดียวกัน ปุ่มเปิดเมนูอยู่ตำแหน่งเดียวกันทุกหน้า ไม่วางสถานะเทคนิคแทนชื่อหน้า
2. แถบล่างคงห้าปลายทาง เรียน / คำศัพท์ / ความก้าวหน้า / รางวัล / โปรไฟล์ ไม่เปลี่ยนลำดับตามหน้าที่เปิด
3. เมนูเปิดเป็นแผงหรือหน้าซ้อนที่มีปุ่มปิดชัดเจน ใช้แถวและไอคอนชุดเดียวกัน แบ่งกิจกรรม ข้อมูล และตั้งค่า หัวเมนูไม่กินพื้นที่ขนาดใหญ่
4. บทฝึกใช้แม่แบบเฉพาะงานร่วมกัน: กลับหรือปิด → ความคืบหน้า → โจทย์ → คำตอบ → ปุ่มและผลตอบกลับ ไม่บังคับให้มีแถบล่างขณะตอบโจทย์
5. หน้าอ่านใช้หัวเรื่อง ระดับโดยประมาณ เนื้อหาที่อ่านสบาย และทางไปคำถาม เนื้อหาไม่ต้องถูกครอบเป็นการ์ดทุกย่อหน้า
6. รางวัลคงกรอบหน้าร่วม แต่ใช้ภาพและกลุ่มรางวัลเฉพาะเนื้อหา เหรียญหรือการฝึกต่อเนื่องไม่ถูกใช้แทนความสามารถทางภาษา
7. เมนูในภาพเป็นตัวอย่าง การนำไปใช้ต้องทำตารางเส้นทางครบทุกฟีเจอร์ รวมร้านค้า ภารกิจ ประวัติ และการฝึกอื่น โดยใช้เงื่อนไขการมองเห็นเดิม
