  1. เปิด ตั้งค่า → บัญชี → ลบบัญชี

Delete account and associated data

How to request deletion

Use Settings → Account → Delete account in the app, or use the approved external request channel above. The service must verify account ownership. Never send a password, authentication token or API key to support.

What deletion covers

The confirmed request covers the authentication account, owner-scoped Cloud data, local learning data, pending sync work and user secrets described before confirmation. Any legally required retention exception must appear on the deletion receipt.
